# Core Principle

### 认知原则

- 少、准确、精要、目的明确、可验证

- 拒绝长篇大论、喋喋不休、无脑投喂

### 认知驱动开发的精髓

- 为AI 构建一个稳定一致、可扩展、可验证的结构

- AI 在整个结构下的工作时的认知，应当保持稳定

- 可扩展、整个结构要适应AI 开发中的功能扩展

- 可验证、AI 必须可以独立验证，自动修复

- DRY 原则。为设计文档，计划，原型设计，编码，bug修复提供全局统一的核心认知，作为唯一事实来源



### 为AI 构建的核心认知应当包括哪些

- 术语

  是全局术语定义事实源

- 结构 

  项目结构、系统交互流程、实体等

- 实体

  有哪些关键实体？如何命名和归类？ 

- 关系 

  数据实体之间的关联关系

- 属性 

  实体有哪些属性：唯一性、不变性、类型、必填、长度、精度 等

- 状态 

  实体有哪些状态、状态是如何变化的

- 功能

  有哪些功能？目的、动作、数据流，作用对象（实体）是什么？

- 界限 
  约束是什么？功能什么条件下可用或不可用？输出、关系/属性/状态变化、异常是什么？



### 文档结构
包括
`
术语与命名
实体、属性 （单独一节）
关系 
状态 
功能
界限 
`
