# v0.1 产品基础

状态：`planned`

阶段：首个 MVP

依赖：无。

事实依据：[`核心认知`](../core-cognition.md)。

展示依据：[`页面风格规范`](../visual-style.md)。

## 目标

建立可承载后续功能的应用壳，并一次完成全局国际化与 Light/Dark 主题基础。

## 范围

- App Shell、Header、主内容区和基础路由。
- English 默认文案与 `zh-CN` 切换。
- Light、Dark 主题切换与偏好持久化。
- 语义颜色 Token、键盘焦点、Loading、Empty、Error 基础状态。
- Language 与 Theme 在 Header 和 Settings 共享同一偏好。
- 所有产品文案通过 i18n key 获取。

## 用户流程

```text
Open application
  -> English + resolved theme
  -> switch Language or Theme
  -> refresh
  -> preference remains
```

## 验收

- 首次访问且没有语言偏好时显示 English。
- 切换中文并刷新后仍为中文。
- 首次主题可跟随系统；无法读取时使用 Light。
- 用户选择 Light 或 Dark 后，刷新仍保留选择。
- 两种语言、两套主题、Desktop 与 Mobile 无文字重叠。
- 键盘焦点可见；状态不只依靠颜色表达。
- 页面内没有散落的硬编码双语文案或非语义主题色。

## 不在范围

- Wallet 连接。
- Identity、Words、Relationship、Artifact。
- BAP ID Lookup 或其他搜索。
- 最终字体、字号比例、间距比例、圆角和动效参数；这些仍待原型确认。
