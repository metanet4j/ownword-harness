## 目标

确认后解析 Inscription Number，支持按 `165` 或 `#165` 找到 Artifact 和当前关联 Identity。

## 范围

- Indexer 确认后的 Inscription Number 写入。
- Artifact Detail 主区域显示 `#<number>` 与 Copy。
- Inscription Number 输入支持纯十进制和 `#` 前缀。
- 解析顺序：Inscription Number、Inscription、Origin、Current Binding、BAP Identity。
- Artifact Details / Proof 显示 Inscription ID、Ordinal Number、Origin、Current Outpoint。
- 有效 Binding 时显示 Associated Identity 和 BAP ID。
- 无有效 Binding 时显示 Artifact 本身与 `No identity is currently associated with this artifact.`。
- reorg 后重新解析编号，并保留其他可验证标识。
- 查询结果提供来源、更新时间和重新解析能力。

## 用户流程

```text
Find an identity
  -> enter 165 or #165
  -> resolve Inscription
  -> resolve Origin
  -> resolve Current Binding
  -> show Artifact and Associated BAP ID
```

## 验收

- `165` 与 `#165` 命中同一 Artifact。
- Copy 得到 `165`，不是 `#165`、缩略值或本地化数字。
- 确认前只显示 Pending confirmation，不显示占位编号。
- reorg 后显示编号需要重新验证，不把 Artifact 标记为已删除。
- Artifact owner、creator 或 signer 任一单独存在时，不自动推导 Current Binding。
- Origin、Inscription ID、Ordinal Number 和 Current Outpoint 能分别复制并保持原值。
- 不存在关联 Identity 时，用户能看到下一步，而不是空白结果。
