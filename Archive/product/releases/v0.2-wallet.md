# v0.2 Wallet

状态：`planned`

阶段：首个 MVP

依赖：[`v0.1`](./v0.1-product-foundation.md)。

事实依据：[`核心认知：结构`](../core-cognition.md#结构)、[`核心认知：全局约束`](../core-cognition.md#全局约束)。

展示依据：[`页面风格规范`](../visual-style.md)。

## 目标

让用户连接 Yours Wallet，并让应用可靠处理选择、取消、失败和 Account Switch。

## 范围

- `Connect Wallet` 入口。
- 单 Wallet 直连与多 Wallet 选择。
- `Connecting`、`Connected`、`Connection cancelled`、`Connection failed` 用户状态。
- Header 中持续显示 Wallet 状态。
- 失败重试与取消后重新连接。
- Account Switch、signed out 等 Wallet 事件监听。
- Account Switch 时清空当前业务上下文，并发出后续模块可订阅的取消事件。

## 用户流程

```text
Connect Wallet
  -> choose Wallet when required
  -> Wallet authorization
  -> Connected
```

异常：

```text
Authorization closed or rejected -> Connection cancelled
Provider or system error          -> Connection failed -> Try Again
```

## 验收

- 用户只看到简化状态，不看到 provider discovery 内部步骤。
- 用户拒绝授权显示 Cancelled，不显示系统 Error。
- 连接失败可重试，且不会产生半连接会话。
- Account Switch 立即清除旧 Account 上下文，不沿用旧授权执行后续动作。
- signed out 后回到 Not connected。
- 应用业务层通过 WalletProvider 抽象调用 Wallet。

## 不在范围

- 计算、发布或解析 BAP Identity。
- Profile、Words、Artifact。
- 其他 Wallet 实现。
