# v0.3 Identity 解析

状态：`planned`

阶段：首个 MVP

依赖：[`v0.2`](./v0.2-wallet.md)。

事实依据：[`核心认知：BAPIdentity`](../core-cognition.md#bapidentity)、[`核心认知：全局约束`](../core-cognition.md#全局约束)。

展示依据：[`页面风格规范：主标识展示`](../visual-style.md#主标识展示)。

## 目标

连接 Wallet 后自动判断当前 Account 是否拥有已发布 BAP Identity，并把用户带到正确下一步。

## 范围

- 调用 Wallet 能力计算当前 Account 的 BAP ID。
- 解析该 BAP ID 是否已发布。
- 区分：已有 Identity、没有 Identity、Identity 已发布但 Profile 不完整。
- 已有 Identity 显示名称、BAP ID 和 Continue。
- 没有 Identity 显示 `Set Up Identity` 入口。
- Account Switch 后重新执行解析。
- BAP ID 显示与复制使用统一组件。

## 用户流程

```text
Wallet Connected
  -> compute current BAP ID
  -> resolve published Identity
     -> found and complete: Continue
     -> found, profile incomplete: Complete profile
     -> not found: Set Up Identity
```

内部计算与解析不作为普通页面步骤展示。

## 验收

- `computeBapId` 成功但 `resolveBapId` 未找到时，不把 Identity 标成已发布。
- 已有 Identity 显示完整可复制 BAP ID。
- Copy 始终得到完整原值。
- Account Switch 后旧 Identity 立即失效，并解析新 Account。
- 解析失败说明影响与重试方式，不把失败误判为“没有 Identity”。

## 不在范围

- 发布新 Identity 或修改 Profile。
- Public Identity。
- 用户输入式 BAP ID Lookup、名称搜索或 Inscription Number Lookup。
