# v0.4 Identity Profile

状态：`planned`

阶段：首个 MVP

依赖：[`v0.3`](./v0.3-identity-resolution.md)。

事实依据：[`核心认知：持久化数据模型`](../core-cognition.md#持久化数据模型)、[`核心认知：持久化状态`](../core-cognition.md#持久化状态)。

展示依据：[`页面风格规范：Identity`](../visual-style.md#identity)。

## 目标

让新用户建立 Identity 与 Profile，让已有用户查看和修改 Profile。

## 范围

- `Set Up Identity` 连续流程：Profile、Review、Wallet Confirmation、Creating、Identity Ready。
- Profile 输入：Avatar、Name、Person/Organization、Description。
- 新 Identity 发布后创建或更新 Profile。
- Profile 不完整用户直接进入补全流程。
- My Identity 页面。
- Edit Profile、Save Changes、取消和失败处理。
- BAP ID 在 Review、成功页和 My Identity 中重点展示并支持复制。

## 用户流程

```text
Set Up Identity
  -> Profile
  -> Review
  -> Create Identity
  -> Wallet Confirmation
  -> Creating
  -> Identity Ready
  -> My Identity
```

修改：

```text
My Identity -> Edit Profile -> Save Changes -> Wallet Confirmation -> Saved
```

## 验收

- 用户不需要选择底层 `publishIdentity` 或 `updateProfile`。
- Review 明确显示当前 Identity 与完整 BAP ID。
- Wallet 拒绝时显示取消，用户输入仍保留。
- 创建失败不产生“Identity Ready”假成功状态，可重试。
- Profile 修改不改变 BAP ID。
- Profile 字段限制引用核心认知，不在前后端各自定义另一套。

## 不在范围

- Key Rotation、Attestation、Revocation。
- Public Identity 和用户输入式 BAP ID Lookup。
- Words、Relationship、Artifact。
