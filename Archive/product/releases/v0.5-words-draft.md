# v0.5 Words Draft

状态：`planned`

阶段：首个 MVP

依赖：[`v0.4`](./v0.4-identity-profile.md)。

事实依据：[`核心认知：Content`](../core-cognition.md#content)、[`核心认知：全局约束`](../core-cognition.md#全局约束)。

展示依据：[`页面风格规范：Write`](../visual-style.md#write)。

## 目标

让当前 Identity 编写、导入、预览并可靠恢复 Markdown Draft。

## 范围

- Write 页面与当前 `Signing as` IdentityReference。
- Markdown 编辑。
- 导入 `.md` 文件。
- Write / Preview 切换。
- Draft 保存状态。
- 页面刷新或重新进入后的 Draft 恢复。
- 清空 Draft 前的明确确认。
- Review 入口；发布动作由下一版本提供。

## 用户流程

```text
My Identity
  -> Write
  -> edit or import Markdown
  -> Preview
  -> Draft saved
  -> leave and return
  -> Draft restored
```

## 验收

- 编辑和预览使用同一 Markdown 源内容。
- `.md` 导入保持 UTF-8 内容；不支持的文件给出明确错误。
- Draft 保存失败时提示风险与重试方式，不能误报 `Draft saved`。
- 刷新后可恢复最后一次确认已保存的 Draft。
- Account Switch 终止当前编辑上下文；旧 Account Draft 不显示给新 Account。
- 页面不显示 Broadcast、Transaction 或协议字段输入。

## 不在范围

- Wallet 签名、发布、Public Post、Proof。
- Published Content Revision。
- 图片、音频、视频和 Attachment。
