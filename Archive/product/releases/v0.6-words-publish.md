## 目标

让当前 Identity 审核、签名并发布 Markdown Post，同时提供可验证 Public Post。

## 范围

- Publish Review：Identity、BAP ID、内容预览、格式、协议与永久性提示。
- `Sign & Publish` 与 Wallet Confirmation。
- Publishing、Cancelled、Failed、Published 结果。
- BitcoinSchema Post：B + MAP + AIP，Markdown / UTF-8。
- Transaction broadcast 后进入 Published，Confirmation 可保持 Pending。
- Public Post。
- Content Proof：作者 BAP ID、签名结果、协议、TxID 和链上状态。
- 发布取消或失败后返回原 Draft。

## 用户流程

```text
Draft
  -> Review
  -> Sign & Publish
  -> Wallet Confirmation
  -> Publishing
  -> Published
  -> Public Post
```

## 异常

```text
Wallet rejected -> Publishing cancelled -> Back to editor
System failed   -> Couldn't publish -> Try Again | Back to Editor
```

两种情况都保留 Draft；只有成功发布后才显示 Published。

## 验收

- Review 显示当前 Identity 和完整可复制 BAP ID。
- 用户签署的内容与 Review 预览一致。
- Wallet 拒绝不显示系统失败，Draft 不变。
- 广播失败不生成 Public Post，Draft 可继续编辑或重试。
- 交易成功广播后显示 Published；未确认只影响 TransactionStatus。
- Proof 明确使用 `Signature valid`，不使用 `Verified Identity`。
- Account Switch 终止待签名或 Publishing 前的敏感流程。

## 不在范围

- 修改已发布版本；Create Revision 后续处理。
- Public Identity 页面。
- Reply、Repost、Like、Tag、Attachment。
- BAP ID Lookup、Relationship、Artifact。
