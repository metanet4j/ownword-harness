# v0.7 Public Identity

状态：`planned`

阶段：首个 MVP，完成后形成首个对外 MVP

依赖：[`v0.6`](./v0.6-words-publish.md)。

事实依据：[`核心认知：BAPIdentity`](../core-cognition.md#bapidentity)、[`核心认知：功能`](../core-cognition.md#功能)。

展示依据：[`页面风格规范：信息层级`](../visual-style.md#信息层级)。

## 目标

让用户通过分享链接查看一个已发布 Identity 的公开资料和公开 Words。

## 范围

- Public Identity 页面。
- Public Profile、BAP ID、公开 Words 列表。
- BAP ID 重点显示和一键复制。
- Public Post 与 Public Identity 互相跳转。
- 未登录或未连接 Wallet 也可查看公开内容。
- 分享链接可直接打开对应 Identity。

## 用户流程

```text
Receive shared Identity link
  -> resolve linked published Identity
  -> Public Identity
  -> view Profile or public Words
```

分享链接的内部解析不等于 MVP 的用户侧 Lookup：页面没有让用户输入 BAP ID 的搜索框，也不提供搜索结果页。

## 验收

- 无 Wallet 连接时，分享链接仍能打开已发布 Public Identity。
- 未发布或不存在的 Identity 显示可理解的 Not found / unavailable 状态。
- Public Identity 首屏显示 Name 与完整或可展开的 BAP ID。
- Copy 得到完整 BAP ID。
- Public Post 能回到作者 Public Identity。
- 当前版本不出现 Find an identity、BAP ID Search 或 Inscription Number Search。

## 不在范围

- 用户输入式 BAP ID Lookup。
- Inscription Number Lookup。
- Follow、Friend、Artifact。
- 私有 Profile 或私有 Content。
