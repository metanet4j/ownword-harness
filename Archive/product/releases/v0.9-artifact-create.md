# v0.9 Identity Artifact 创建

状态：`planned`

阶段：第三阶段

依赖：[`v0.8`](./v0.8-relationship.md)。

事实依据：[`核心认知：BapNFT`](../core-cognition.md#bapnft)、[`核心认知：功能`](../core-cognition.md#功能)、[`核心认知：全局约束`](../core-cognition.md#全局约束)。

展示依据：[`页面风格规范：Identity Artifact`](../visual-style.md#identity-artifact)。

## 目标

允许已发布 Identity 创建一个 1Sat Identity Artifact，并把创建过程与链上确认状态分开表达。

## 范围

- Identity Home 的 `Create Artifact` 入口。
- 选择 Artifact 内容、Preview、Review。
- Review 显示 Creating as、BAP ID、内容预览和 `Inscription Number: Assigned after confirmation`。
- Wallet Confirmation、Creating、Transaction broadcast、Created。
- 使用 Wallet `inscribe` 能力创建 Ordinal。
- 使用 `ord` 类型所需 MAP 元数据；字段语义引用核心认知。
- 创建成功后按产品规则尝试设置 Current Artifact。
- 确认前不显示预测编号。

## 用户流程

```text
Create Artifact
  -> Choose Content
  -> Preview
  -> Review
  -> Wallet Confirmation
  -> Creating
  -> Transaction broadcast
  -> Created
```

## 验收

- 创建 Artifact 不要求用户先创建或修改 Words。
- 创建 Artifact 不改变 BAP Identity 或 BAP ID。
- Wallet 取消或失败后不显示 Created，已输入内容可恢复或重试。
- Created 页面显示 Transaction；Inscription Number 显示 `Pending confirmation`。
- 不使用 txid、Origin、Outpoint 或本地序号推测 Inscription Number。
- Artifact 创建签名在 UI 只称 `BAP signature`，底层封装以实现验证结果为准。
- 当前 Identity 没有 Artifact 仍可使用 Words 与 Relationship。

## 阻塞项

- `signWithBAP` 的最终 AIP / Sigma 封装需以当前 SDK 生成输出和验证器确认。
- IdentityNFTBinding 的权威事实归属需先确认；在确认前只能实现明确的产品暂存状态，不能把它写成协议事实。
- 当前生产 Inscription Number 查询 endpoint 不影响创建广播，但影响后续解析版本。

## 不在范围

- Inscription Number 最终分配与 Lookup。
- Artifact Transfer、Change Current、Unbind。
- Marketplace、Collection、Royalty。
