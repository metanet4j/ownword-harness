**测量纪律（两次踩坑后定稿，务必沿用）**：

1. 编译错误总数会被「找不到已删除类」这类硬错误**提前中止**而掩盖（实测：修 1 个 import 后从 2 跳到 200）；
2. 错误总数会被 javac 上限**封顶**（实测恒为 200，错误降到上限以下前读数不变）。

因此**只能用「有错误的文件数」与「旧引用文件数」作进度尺**，且每轮先重跑一次 `test-compile` 取真实基线。
