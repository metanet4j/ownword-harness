## 3. 每仓库编译命令

**固定前置**（每次都要；不设 `JAVA_HOME` 会落到全局 JDK 8，`--release 25` 直接失败；`-s` 保证依赖进隔离仓库）：

```bash
TASK=/home/haodev/ownword/_task/backend-worktree/boot4-java25-upgrade
export JAVA_HOME=$HOME/.sdkman/candidates/java/25.0.4.1-tem
MVN="$HOME/.sdkman/candidates/maven/3.9.16/bin/mvn -s $HOME/.m2/metanet4j-settings.xml -B"
```

**逐仓库**（顺序不可乱：`parent` 先 install，下游才能解析父 POM；子模块 `<parent>` 未写 `relativePath`）：

```bash
# ① parent（packaging=pom，只发 POM，必须 -N）
(cd $TASK/metanet4j-parent && $MVN -N install)

# ② base
(cd $TASK/metanet4j-base && $MVN clean install)

# ③ sdk
(cd $TASK/metanet4j-sdk && $MVN clean install)

# ④ component（聚合工程，递归 21 个子模块）
(cd $TASK/metanet4j-component && $MVN clean package)
```

**只做编译门禁**（跳过用例执行，仍编译测试代码）：在上面第 ②③④ 条末尾加 `-DskipTests`。

**跑测试门禁**（排除需联网/外部依赖的用例；这是本报告 §4.2 的口径）：

```bash
(cd $TASK/metanet4j-base      && $MVN clean test)
(cd $TASK/metanet4j-sdk       && $MVN clean test -DexcludedGroups=external)
(cd $TASK/metanet4j-component && $MVN clean test -DexcludedGroups=external)
```

**一键环境与状态自检**：`cd $TASK && ./init.sh`（秒级；`--full` 追加真实构建与分模块执行数）。
