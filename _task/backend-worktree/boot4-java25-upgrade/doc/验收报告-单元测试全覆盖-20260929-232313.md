## 6. 剩余限制

**SFTP 的本地可控服务集成未完成。** `SftpFileClient.doInit()` 通过 hutool `Sftp`
（底层 JSch）建立 SSH 连接，其成功构造行按精确清单登记为覆盖例外（2 行）。

这与 FTP 的情况不同：FTP 可以按 RFC 959 完整实现客户端用到的命令子集，并被真实的
commons-net 客户端验证；SFTP 需要完整的 SSH 协议栈（版本交换、密钥交换、主机密钥
验证、通道层、SFTP 子系统），手写实现既不现实，也不能代表真实 SSH 行为。
本机没有 sshd 二进制与 SSH 服务镜像，模块依赖里只有客户端库 jsch。

补齐该项需要一个可用的 SSH/SFTP 服务，两条路径都需要胡先生确认：
给 `ownword/infra` 增加一个 sftp 服务（属于跨任务共享基础设施变更），或在本机安装
openssh-server（属于宿主环境变更）。两者都超出本任务当前的授权边界。
