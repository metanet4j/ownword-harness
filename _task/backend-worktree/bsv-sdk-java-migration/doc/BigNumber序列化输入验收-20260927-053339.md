# BigNumber 序列化原输入局部验收

固定上游 `src/primitives/__tests/BigNumber.serializers.test.ts` 的全部 16 例已通过局部标准验收。正式 Java 证据绑定提交 `7247aea`；完整 P0 验收尚未通过。

## 结果

| 项目 | 结果 |
| --- | --- |
| 正式 TS / Java 原测试 | 16 / 16；失败、错误、跳过均为 0 |
| 真实入口输入 | 106 / 106，逐样本一致 |
| 原断言实际值 | 55 / 55，逐条精确比较通过 |
| 原 Java 主体与独立重放 | 55 条原 matcher、actual、expected 全部一致 |
| 共享 Java 重放器累计回归 | 算术 52 + 位运算 20 + 序列化 16，共 88 / 88 |
| 累计重放实际观察 | 2138 输入、752 断言，与 TS 逐项一致 |
| 标准 bundle / compare | PASS，`formalAcceptance=false` |

原文件无循环，全部构造、静态工厂、字节序、符号位、最小编码和异常断言均保留。`BigNumberInputReplay` 新增字节数组、数组结果、静态工厂及 `not.toThrow` 的实际返回值表征；语料仅包含真实输入、返回引用和原 matcher，不把 TS actual 作为 Java 返回值。

四处原 Java 异常检查恢复为原 `toThrow(text)` 的单次记录。五字节 script number 用例保留原禁止文本 `script number overflow`，由真实工厂调用生成返回值或异常，再执行原消息条件。返回值通过现有公开 `ParityRecorder.Raw` 记录实际 BigNumber 的字符串表征，未改通用记录器。`toScriptNum` 与 `toSm` 按原源码顺序求值。Java 生产代码及映射文件未因本批变更。

采集器排除通用记录器的字符串格式化调用，避免把观测过程计作原入口。共享 TS 回归中，算术 1354 条、位运算 1375 条完整事件的 JSON 结构和值均与已提交语料相等；这些数量包含入口和原断言引用。

## 证据

以下路径均相对任务根目录。

- 输入计划：`bn-serializers-input-plan.json`；局部 catalog/mapping：`.cache/evidence/bn-serializers-plan-20260927/`。
- 固定语料：`metanet4j-bsv-sdk/src/test/resources/migration/bn-serializers-inputs.jsonl`。
- 正式 TS / Java：`.cache/evidence/bn-serializers-ts-formal-20260927/`、`.cache/evidence/bn-serializers-java-formal-20260927/`。
- 标准结果：`.cache/evidence/bn-serializers-parity-20260927.json`、`bn-serializers-bundle-20260927.log`、`bn-serializers-compare-20260927.log`，均在 `.cache/evidence/`。
- 原 Java 主体观察：正式 Java 目录的 `original-assertions.jsonl`，55 条与独立 replay 相等。
- 适配器 RED：`.cache/evidence/bn-serializers-adapter-red-20260927.log` 和同名 XML；16 例中缺少字节、数组结果及静态工厂适配导致 1 failure、13 errors，2 例通过。
- 累计 GREEN：`.cache/evidence/bn-serializers-java-green2-20260927/`，保存 88 例日志、三份 Surefire XML、2138 输入、752 独立重放断言及原序列化主体 55 断言。
- 真实工厂篡改：`.cache/evidence/bn-serializers-factory-tamper-20260927.log` 和同名 XML。把 `fromHex('0100', 'little')` 的输入改为 `0200`，真实返回由 1 变成 2，后续原接收者状态核对明确拒绝；单例 1 failure、0 errors。
- 正式轨迹篡改：`.cache/evidence/bn-serializers-tamper-inputs-20260927.log`、`bn-serializers-tamper-assertions-20260927.log`。输入 `0100→0200`、实际输出 `5→6` 均由标准封装退出 2 拒绝；独立实际值比较也拒绝输出篡改。
- 共享 TS 回归：`.cache/evidence/bn-serializers-arithmetic-regression-20260927/`、`bn-serializers-binary-regression-20260927/`。
