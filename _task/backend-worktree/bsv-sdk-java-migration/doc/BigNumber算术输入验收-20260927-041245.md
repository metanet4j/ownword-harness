## 重跑入口

从任务根目录执行；选择新的 `bn_evidence` 路径，正式 capture 拒绝覆盖旧输出。Java 运行前保持目标工程已提交且工作树干净，测试使用宿主环境。

```bash
bn_evidence=".cache/evidence/bn-arithmetic-rerun-$(date +%Y%m%d-%H%M%S)"
bn_plan='.cache/evidence/bn-arithmetic-plan-20260927'
bn_replay='metanet4j-bsv-sdk/src/test/resources/migration/bn-arithmetic-inputs.jsonl'

  --catalog "$bn_plan/catalog.json" --mapping "$bn_plan/mapping.json" \
  --input-plan bn-arithmetic-input-plan.json \
  --inputs "$bn_evidence/ts/inputs.jsonl" --assertions "$bn_evidence/ts/assertions.jsonl" \
  --report "$bn_evidence/ts/jest.json" --output "$bn_evidence/ts/manifest.json" -- \
  python3 capture-bn-arithmetic-side.py ts \
  --catalog "$bn_plan/catalog.json" --mapping "$bn_plan/mapping.json" \
  --report "$bn_evidence/ts/jest.json" --replay "$bn_replay"
python3 evidence-bundle.py capture --side java \
  --catalog "$bn_plan/catalog.json" --mapping "$bn_plan/mapping.json" \
  --input-plan bn-arithmetic-input-plan.json \
  --inputs "$bn_evidence/java/inputs.jsonl" --assertions "$bn_evidence/java/assertions.jsonl" \
```
