本批保留显式 `undefined`、`0`、`NaN`、96 位异常、双参数空构造、空二进制往返、非字符串口令异常及字符串返回。原空二进制往返测试恢复 `original` 构造、`toBinary()`、`restored` 构造、`fromBinary()` 的源码调用顺序。

`loadRandom(Number)` 公共签名保持不变，新增 `loadRandom(Object)` 只接受 `Undefined.INSTANCE`、null 或 Number，再委派已有 Number 实现。Java 原测试用 `(Object) Undefined.INSTANCE` 真实进入公开入口；输入账本保留 `Undefined`，没有把 Java null 直接记录成 TS undefined。`0` 和 `NaN` 分别保留为独立原数值，不能互换。对应 API 映射只有该入口的说明更新。

共享采集器区分两个原文件；词表 `value` 的采集仅限原 `Mnemonic.test.ts:18` 站点，采集器自身状态读取不产生额外样本。原 50 例重新运行后的 258 输入和 158 断言与先前固定语料逐项一致。补充 8 例无需新增断言比较语义规则。
