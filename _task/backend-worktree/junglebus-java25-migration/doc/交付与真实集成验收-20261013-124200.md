## 真实 100 条测试

使用 Java SDK 和 [LiveSubscription.java](../metanet4j-junglebus/examples/LiveSubscription.java) 运行：

```bash
./live-test.sh e2f91b57c5005db42b88b3f346bb8c751735975076201fb7419f5dc346ac22fd artifacts/live-json-20261013-123500 JSON
```

| 条件与结果 | 实际值 |
| --- | --- |
| 目标 | `junglebus.gorillapool.io`，TLS，JSON 普通模式 |
| 起始区块 | 720000 |
| 执行时间 | 2026-10-13 12:34:35–12:34:44，Asia/Shanghai，约 9.6 秒 |
| 接入 | 匿名 Token 获取、连接 Token 刷新、WebSocket 握手成功 |
| 通道 | 区块、控制、Mempool 均确认订阅成功 |
| 输出 | 100 条区块交易，0 条 Mempool 交易，100 个不同交易 ID |
| 高度范围 | 720084–722045，订阅过滤后的实际命中范围 |
| 交易正文 | 共 59697 字节，100 条均能双 SHA-256 计算出服务端交易 ID |
| 控制日志 | 2044 条 BLOCK_DONE，2148 条未知码 199，全部保留 |
| 错误 | 0 |
| 停止 | 收到第 100 条后停止输出；取消获得确认；断开并最终 CLOSED |

提供的 64 位字符串用于订阅 ID，SDK 通过它申请匿名 Token；没有将其当作 JWT。交易输出与状态日志分别保存，凭据没有写入产物。

完整交易见 [transactions.jsonl](../artifacts/live-json-20261013-123500/transactions.jsonl)，状态见 [events.jsonl](../artifacts/live-json-20261013-123500/events.jsonl)，结果见 [summary.json](../artifacts/live-json-20261013-123500/summary.json)，计数和校验摘要见 [validation.json](../artifacts/live-json-20261013-123500/validation.json)。复跑需要使用新的输出目录，以保护已有证据。

## 验证边界

本次线上验收覆盖 JSON 普通模式和实际接收到的区块交易；Protobuf／Lite 仅通过离线验证。Mempool 通道确认成功，但达到 100 条之前没有收到 Mempool 交易，不能将订阅确认描述为实际 Mempool 数据验收。

地址详情额外字段、REST 交易字节编码、`/bin` 鉴权、精确服务版本和线上故障恢复未验证。样本不能证明起始块包含规则或跨通道块完成保证；安全重放起点仍保持原始 fromBlock，允许重复，调用方按交易 ID 幂等处理。REORG 只交付通知，不代替业务数据回滚。

Javadoc 插件和资源复制配置依据 [Apache Maven 官方用法](https://maven.apache.org/plugins/maven-javadoc-plugin/usage.html)及[资源说明](https://maven.apache.org/plugins/maven-javadoc-plugin/examples/javadoc-resources.html)，实际产物已经核对。
