# 基督教要义（Institutes of the Christian Religion）

加尔文《基督教要义》朗读稿的本地存档，来源 <https://cmchurch.org/《基督教要义》加尔文/>，共 84 篇：卷首 4 篇、第一卷 18 篇、第二卷 17 篇、第三卷 25 篇、第四卷 20 篇，正文合计约 107 万字（不含空白字符）。

原文为约翰·加尔文（John Calvin, 1509-1564）1559 年拉丁文定本。朗读稿由「基督、使命与教会」自 2019 年 11 月起重译，底本是 Ford Lewis Battles 据 John T. McNeil 编订的 1559 年拉丁版所译、Westminster John Knox 1960 年出版的英译本；卷首《英译本导言》则摘自 2017 年宗教改革五百周年修订版译本。

抓取、转换与排版流程见[上级说明](../README.md)，本书条目与排版参数见 [manifest.json](manifest.json)。

## 结构

| 文件 | 说明 |
| --- | --- |
| `目录.md` | 总目录：卷首与四卷、84 章 |
| `00-…-…md` | 卷首四篇：朗读版导言、加尔文序言、英译本导言、致法王法兰西斯一世书 |
| `1-01.md` … `4-20.md` | 各卷章节，文件名前缀为「卷号-卷内章序」 |
| `基督教要义朗读版.docx` | 全书 Word 文档 |
| `基督教要义朗读版.html` | 单文件 HTML 阅读版 |
| `基督教要义朗读版.epub` | EPUB 3，Apple Books 可读 |

`manifest.json` 的 `part` 字段承载卷次，Markdown、Word 与 HTML 的目录都按「卷 → 章」两层分组；`category` 未使用。章节 slug 用 `卷号-章序`（如 `3-11`），全 ASCII 且稳定排序，正文里的卷名与章题仍用中文全称。

## 本书要点

- 每章正文是站点发布的朗读稿，一级标题为章题，`h4` 小节统一降为二级标题。
- 页首朗读音频写入章首引用行（`> 朗读音频：`），与源页面一致；有四篇没有音频。
- 正文大量使用比例号「∶」（U+2236）作分节符（如「徒17∶28」），`lib/scripture.py` 原先只认半角与全角冒号，已补上这一写法。
- 部分章题含中文分号与顿号，slug 因此不复用章题。

## 圣经引用对照

`manifest.json` 声明了 `scripture` 段，HTML 版把「（徒17∶28）」这类出处渲染成可点击的编号，点开在原地展开和合本原文。

- 引用块 3,472 处，经文 181,661 字。
- 未命中 3 处，均因源文卷章号有误，和合本无对应经文：`以弗所书 10:30`、`约翰一书 12:20`、`约翰一书 12:27`（两书分别只有 6 章与 5 章）。产物里这些出处标灰不可点，正文按源文保留，未改写。

## 校验

在 `_task/book-scrape` 下执行 `python lib/verify_book.py "基督教要义-朗读版"`：

- Word 5,060 段、1,054,212 正文字符；6 处字面星号来自源文的小节标题，原文在标题末尾用 `*` 标脚注，转换后按源样保留
- 总目录 84 条链接全部有效

## 与旧版存档的差异

上一版用本书目录内的 `抓取脚本.cjs`（WordPress REST API 转 Markdown）与 `md转word.cjs`（pandoc 合成 docx）单独成书，产物是四卷目录树加 `word/` 一个 docx，与其余书的流程和版式都不一致。本次改用 `lib/` 的共享流水线重抓重排，旧脚本与它生成的目录树、`word/` 产物已删除。
