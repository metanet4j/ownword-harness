# 威斯敏斯特信条（The Westminster Confession of Faith）

《威斯敏斯特信条》解读抓取结果，来源 <https://cmchurch.org/《威斯敏斯特信条》/>，共 33 章，另含卷首简介、引证经文用法与已发布的章节自测题。

信条为威斯敏斯特会议 1646 年底完成，中译底本为美国正信长老会（OPC）1956 年版。

抓取、转换与排版流程见[上级说明](../README.md)，本书条目与排版参数见 [manifest.json](manifest.json)。

## 结构

| 文件 | 说明 |
| --- | --- |
| `目录.md` | 总目录：简介、使用方法、33 章、自测题 |
| `000-简介.md` | 卷首简介（威斯敏斯特会议与信条的由来、八个部分的划分、中译本源流） |
| `001-怎样使用引证经文学习信条.md` | 引证经文的使用说明 |
| `002-第1章-论圣经.md` … `034-第33章-论最后审判.md` | 33 章，每章含中文章节、英文对照与逐节解读 |
| `035-第1-5章自测题.md` | 站点已发布的第 1-5 章自测题 |
| `威斯敏斯特信条解读.docx` | 全书 Word 文档 |

每章正文的组织是：中文条文（节号用「一、二、三」）→ 英文对照 → 「解读：」及其条目。第 1 章 10 节、第 33 章 3 节，中间各章依此类推。

## 未收录

目录页把 33 章之后的「讲解课程」列为 33 个条目，但这些条目在源页面里是纯文本、没有链接，站点上没有对应页面，因此未抓取。自测题目录列了 7 组，站点只发布了前 3 组，其中只有第 1-5 章那组有链接，故只收录这一组。

- 总目录 36 条链接全部有效
