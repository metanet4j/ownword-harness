# 威斯敏斯特大教理问答（The Westminster Larger Catechism）

《威斯敏斯特大教理问答》抓取结果，来源 <https://cmchurch.org/《威斯敏斯特大教理问答》/>，共 196 问，另含卷首简介。

问答为威斯敏斯特会议 1648 年 7 月完成，中译底本为美国正信长老会（OPC）1956 年版。

抓取、转换与排版流程见[上级说明](../README.md)，本书条目与排版参数见 [manifest.json](manifest.json)。

## 结构

站点按「分类」发布，一个分类页放同一主题下的若干问答（1 至 10 问不等），因此本书一章对应一个分类页：

| 文件 | 说明 |
| --- | --- |
| `目录.md` | 总目录：简介、三个部分、93 个分类 |
| `000-简介.md` | 卷首简介（威斯敏斯特会议与本问答的由来） |
| `001-一-人生的首要目的.md` … `093-九十三-主祷文结语.md` | 93 个分类，覆盖第 1 至 196 问 |
| `威斯敏斯特大教理问答.docx` | 全书 Word 文档 |

分类页里每问以「N问：…」起头，后接「答：…」，再跟英文对照，Markdown 与 Word 中都保留为二级标题加正文。

## 校验

在 `_task/book-scrape` 下执行：

```bash
python3 lib/scan_questions.py "威斯敏斯特大教理问答-questions-answers"
python3 lib/verify_book.py    "威斯敏斯特大教理问答-questions-answers"
```

- 覆盖问答 196 个，编号 1-196 无缺口；页面数与目录条目一致
- 94 章全部命中 Markdown 与 Word，无缺失段落
- Word 1,519 段左右、7.3 万正文字符，无星号残留
- 总目录 94 条链接全部有效

`scan_questions.py` 报告的重复编号 140-142 是分类页正文里对相关问答的回指，不是重复抓取。
