## 模块与后端数据

公共契约 [contracts.ts](own-word-web/lib/wallet/contracts.ts) 与 bf25772 相比无差异，注册入口为 [index.ts](own-word-web/lib/wallet/index.ts)。业务只使用 WalletProvider、OwnWord DTO 与固定错误码；官方核心、助记词和 SDK/CWI 细节是私有实现。ESLint 阻止页面/业务导入具体适配器、核心或测试控制，也阻止钱包模块依赖业务资料和同步。

BAP/B/MAP/AIP 编码、冻结校验、IndexedDB 流程日志和同步位于 lib/domain。已签名原交易先保存，Mock 广播接受后才同步。普通 BAP 资料、头像与已广播业务查询来自真实后端，无 simulationPreview 数据来源；未广播准备恢复封装在钱包模块。

| API | 实际用途 |
| --- | --- |
| POST /api/v1/transactions/sync | 提交 operationId、bapId、txid、rawTx，后端独立解析验签及幂等保存 |
| GET /api/v1/identities/{bapId} | 状态、资料、签名者与交易引用，scope 区分主网和隔离空间 |
| GET /api/v1/assets/{txid} | 真实图片字节，缓存丢失时从原交易重建 |
| GET /api/v1/identity-operations/{operationId} | 已存储及旧未决操作恢复 |
| GET /api/v1/transactions/{txid} | 已广播未知结果恢复；live 缺记录时按真实网络读取 |

五类旧业务 POST 已删除。health 为内部就绪检查；钱包 RPC 是私有传输。头像通过 B/MAP/AIP 发布真实字节，Profile 引用 b://TxID；首次带头像依次 ID → 图片 → ALIAS，部分失败保留已完成步骤。

后端收到完整、已签名的原交易十六进制 rawTx。官方 signAction 返回 AtomicBEEF；适配器取其中当前交易并转换为 rawTx，不把诊断 JSON 发给后端。
