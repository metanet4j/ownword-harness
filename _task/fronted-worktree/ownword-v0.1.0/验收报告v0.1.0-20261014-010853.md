## 模块与接口

公共接口为 [contracts.ts](own-word-web/lib/wallet/contracts.ts)，注册入口为 [index.ts](own-word-web/lib/wallet/index.ts)。业务只依赖 WalletProvider、OwnWord DTO 和固定 WalletErrorCode；不暴露 CWI、WalletInterface 或 SDK Transaction。具体 SDK/RPC 在 adapters；替换钱包实现同一接口并修改注册入口，业务与后端契约保持不变。

接口包含连接、会话、公钥、内容签名、交易准备、未广播准备恢复、准备取消与独立广播。钱包不依赖 Profile、业务 HTTP、资料投影或同步状态。正常业务不通过 listOutputs、basket、SDK getProfile 或钱包历史读取 BAP 资料。ESLint 阻止业务导入具体适配器及 SDK 钱包类型，也阻止钱包模块依赖业务代码。

身份模块负责 BAP/B/MAP/AIP 编码、冻结校验、日志和同步。适配器用真实 Actions 完成资金输入、找零和签名，createAction/signAction 均传 noSend=true。本地广播 Mock 独立于准备，不修改原交易和 TxID。实际 Yours 准备不广播的能力未验，live 默认不放行该能力；不凭 noSend 参数声称插件已通过。

IndexedDB 先保存已签名 rawTx、冻结输出和账户；广播接受后保存回执，再 POST 后端。拒绝不写后端，未知保持未决，同步失败只重放原交易。未广播准备回执丢失由模块 recoverPreparation 封装；已广播业务记录查后端。旧无 rawTx 操作不能盲目重签。

| API | 实际用途 |
| --- | --- |
| POST /api/v1/transactions/sync | 广播接受后提交 operationId、bapId、txid、rawTx，后端独立验签并按 TxID 幂等存储 |
| GET /api/v1/identities/{bapId} | 普通 profile、状态、签名者和交易引用统一后端读取，scope 区分主网与测试空间 |
| GET /api/v1/assets/{txid} | 真实图片字节，缓存丢失时从原交易重建 |
| GET /api/v1/identity-operations/{operationId} | 已存储操作与旧未决操作恢复，前端有实际消费者 |
| GET /api/v1/transactions/{txid} | 已广播未知结果恢复；先查存储，live 缺记录时真实网络读取 |

旧意图登记、preflight、submission-attempts、wallet-results、avatar-uploads 五类 POST 已删除。GET transactions 因新恢复流程有实际用途而保留，其 live 正向浏览器分支未验。health 为内部就绪检查，钱包 RPC 属于私有传输。

头像通过 B/MAP/AIP 发布真实字节，Profile 引用 b://TxID。首次带头像按 ID → 图片 → ALIAS，最多三笔；部分取消不重复已完成步骤。
