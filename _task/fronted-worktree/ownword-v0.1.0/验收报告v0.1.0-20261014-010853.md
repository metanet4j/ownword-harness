## 当前 API 与行为

| 接口 | 用途 |
| --- | --- |
| POST /api/v1/transactions/sync | 钱包回执后提交 operationId、bapId、txid、rawTx；后端独立验签并从原交易派生资料或图片，按 TxID 幂等同步 |
| GET /api/v1/identities/{bapId} | 读取公开身份与明确隔离的模拟预览；缺真实历史及 checkpoint 时保持 unknown |
| GET /api/v1/assets/{txid} | 读取链上图片缓存；缓存丢失时从保存的原交易重建 |
| GET /api/v1/identity-operations/{operationId} | 只读迁移恢复旧无 TxID 操作；前端仍有实际消费者，暂时保留 |

旧 POST 意图登记、preflight、submission-attempts、wallet-results、avatar-uploads 已直接删除；旧入口真实返回 404/405，不保留 410 空接口。无前端用途的公共 GET transactions 已删除，主网交易读取保留为后端内部校验能力。health 为内部服务就绪检查；钱包 RPC 是钱包传输边界。

核对页只作本地校验和预览。浏览器 IndexedDB 原子登记转交标记，保存冻结业务输出、账户与钱包回执；存储失败或账户变化阻止钱包转交。钱包可在 createAction 内处理，也可分 createAction/signAction；两条路径均先核对真实签名输出，之后才同步后端。

头像使用 B/MAP/AIP 原图片字节，Profile 引用 b://TxID。首次带头像按 ID → 图片 → ALIAS 顺序；最多三笔交易与多次授权，核对页说明公开与不可撤回的部分成功。取消后可确认剩余步骤，不重复已完成图片或 ID。同步失败显示 sync-pending，只重放同一 TxID；无回执则只读查询原操作标签。
