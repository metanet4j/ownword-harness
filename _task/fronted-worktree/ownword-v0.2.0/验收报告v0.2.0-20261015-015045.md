## 技术验证

前端完整回归 48 项通过，零失败、零跳过；lint、typecheck、生产构建通过。后端关联模块共 189 项通过，模块执行数见 [backend-counts.json](evidence/d05/backend-counts.json)。测试、构建输出及最终浏览器结果在 [D05 证据目录](evidence/d05/)。

后端标题解析修复了代码块中 `#` 被误认标题的问题，使用固定 `org.commonmark:commonmark:0.30.1`；依赖及 AST 用法依据[官方说明](https://github.com/commonmark/commonmark-java)。真实 HTTP 复查表明标题从 fenced example 变为 Actual title，正文 SHA-256 与原交易均保持不变。

最终浏览器复查覆盖已发布列表、准备期间账户变化、跨标签接管、历史操作入口、本地日志读取失败、真实 API 停止/恢复、钱包失败、Proof 未验证/签名损坏、作者资料弹窗与焦点返回。320px 深色阅读页无横向溢出；阅读、作者弹窗和历史页的 axe 检查均为零违规。详细结果见 [checks.json](evidence/d05/checks.json)。

历史会话记录了主动注入的存储故障、旧构建切换期间的 ChunkLoadError 和 Adobe 字体网络失败，原始记录已保留。最终生产构建使用全新浏览器会话复查，未处理异常为零；外部字体仍依赖网络。

## 原型对照

原型与实现使用相同 Markdown 样例比较。1440px 下正文左边缘 416.453px、宽度 607.094px、H1 24px、目录宽度 220px、作者按钮宽度 203.5px 一致。对应图片为[原型](evidence/d05/prototype-reader-1440.png)与[实现](evidence/d05/implementation-reader-1440.png)；编辑器对照沿用 [D01 对照图](evidence/d01/editor-prototype-match.png)。尺寸完整记录见 [reader-metrics.json](evidence/d05/reader-metrics.json) 与 [prototype-metrics.json](evidence/d05/prototype-metrics.json)。

真实界面按已批准设计增加隔离来源、观测时间和历史覆盖依据；隔离来源说明使正文起点比原型下移 43px。访客返回现有首页，作者入口查看当前身份资料；未扩展 v0.4 Find 或公开主页。
