## 四模块页面、箭头与居中复核

用户反馈的视觉重心问题来自不同宽度的表单与确认页保留旧左侧排布。当前列表主体为 960px，单列表单与确认页为 720px，并与导航、页脚共享屏幕中心轴；文字保持自然阅读对齐。图片和表单并排时整体居中，默认内容不保留空的媒体列。编辑器按工作需要使用较宽视野。

| 实际问题 | 修复与验收 |
| --- | --- |
| 返回箭头比例重，文字入口重复方向符号 | 返回使用绑定 S2 Arrow，展开和图标入口使用 Chevron；尺寸读取对应 Token，保留 44px 命中区域及键盘焦点 |
| 创建、确认及图片转移页面偏左 | 统一外层宽度与居中规则，默认创建和确认均为 720px；两列图片转移整体 960px；桌面实测左右留白相等 |
| Artifact 关联身份的复制按钮强制换行 | 移除局部宽度覆盖，BAP ID 与复制按钮中心高度一致 |
| 编辑器 ActionMenu 形态、帮助浮层重复 | 使用 ActionButton 形态及 isQuiet；上下文帮助只显示一层，方向键、End、Escape 与焦点恢复通过 |

## 设计系统与交付边界

实际绑定为 `ReactSpectrumS2_ad4872`，来源声明 `@react-spectrum/s2@1.6.0`、Tokens `14.15.0`。原型使用继承的轻量视觉组件及应用行为封装，不等同官方生产运行时。媒体尺寸和标题行数属于 OwnWord 页面布局，未更换设计系统或修改源 Token。

对照绑定版本的[官方 ActionButton](../../../reference/react-spectrum-main/react-spectrum-main/packages/@react-spectrum/s2/src/ActionButton.tsx)、[Button](../../../reference/react-spectrum-main/react-spectrum-main/packages/@react-spectrum/s2/src/Button.tsx) 和 [Tooltip](../../../reference/react-spectrum-main/react-spectrum-main/packages/@react-spectrum/s2/src/Tooltip.tsx)，已修复此前记录的圆角、悬停／按下、键盘提示差异。当前源由 v0.4.0 分支内维护，绑定版本与 namespace 保持一致。R11 的组件核对和页面验收已完成；R12 正在做最终交付审计。

本轮只做受影响页面的代理视觉评审与实现验收，未运行全站无障碍矩阵或生产验证。身份、Wallet、签名、广播、索引与 Proof 使用确定性样例，真实适配边界仍以核心认知第 12 节为准。当前执行 R12 最终验收；已交付成果保留 `needs-review`，供用户最终视觉复核。
