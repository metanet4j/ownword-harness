# v0.4.0 Identity 个人主页原型交付

当前交付完成整站体验优化 R03：以个人主页确定信息层级和分组，将共用标题、辅助标签、标识与头像表达应用到相关页面。已实现、验证并完成代理截图审核，状态为 `needs-review`，等待用户视觉复核。

需求与页面方案以[当前 PRD](../../system-design/spec/prd/v0.4.0/设计文档v0.4.0-个人主页-20260918.md)和[核心认知](../../system-design/spec/核心认知.md)为准；逐项状态见[任务清单](feature_list.json)。

## 预览与复现

[打开 Maya Chen 公开主页](http://127.0.0.1:4314/#/identity/2FfJxP9rMWqeBZQ3KxL2wZsLbS7xw8bVpD)。公开浏览无需连接 Wallet，页面可以阅读作品、筛选媒体、查看身份详情与公开名单。关系操作通过样例钱包演练。

在本任务目录运行 `./init.sh --serve`；Windows 使用 `./init.ps1 -Serve`。源码修改后在原型目录运行 `npm run build`，回到本目录运行 `./init.sh`；本轮浏览器复现命令为原型目录中的 `node verify-experience.mjs`。

## 设计审核

审核依据为 OwnWord 四项设计原则，以及用户指定的 [frontend-design](../../../.agents/skills/frontend-design/SKILL.md)。baoyu-design 组织方案和预览，react-spectrum 核对实现。颜色、字体和组件服从项目绑定 S2，通用技能中的自由选色与字体建议按项目约束应用。

| 页面或区域 | 观察与用户影响 | 修改方向 | 实际复核 |
| --- | --- | --- | --- |
| 公开主页 | 身份类型、标识、详情、关系操作分散占行，手机作品出现较晚 | 姓名与类型、标识与详情、操作与人数分别成组 | 320×720 首条作品标题从约 752px 提前至 654px，完整显示；桌面约 592px 提前至 493px |
| 内容筛选 | 窄屏的最后一个类型需要横向查找 | 按常规辅助字级和 S2 间距呈现，保留操作区域 | 五个标签在 320px 下完整可见，区域至少 44px，Home/End 与焦点反馈可用 |
| 关系列表 | 完整主页介绍和重复关系入口挤占名单，读取失败出现重复提示 | 紧凑页头、所属主页返回入口，单处错误与重试 | 首个身份在手机首屏可见；错误时保留已加载行、上次结果和核实时点 |
| 共用标识 | 文字复制按钮占用标识宽度，失败提示缺少处理方法 | 公开页使用 S2 图标按钮，失败展开完整值并提示手动复制 | 实际复制后粘贴得到完整 BAP ID；失败、详情完整值及焦点返回检查通过 |
| 标题与辅助信息 | 管理任务与作品标题的角色不够明确，辅助标签普遍大写且字距较宽 | 管理标题使用 S2 无衬线角色，作者、作品和阅读保留衬线角色；标签使用常规大小写 | 核对身份、内容、Artifact、查找、编辑、阅读与版本页面；标题不超过 28px |
| 无头像回退 | 渐变无助识别，与“我的身份”回退不一致 | 统一中性 S2 表面与文字角色 | 浅深主题可读；本轮深色主页 axe 对比度检查无待判定项 |

以上是对实际预览和关键截图的审核，未将设计方向或自动化数据当作用户批准。秩序由对齐和字体角色表达，关系由紧密分组表达，密度由首屏内容与操作区域共同约束，强调来自身份、作品和实际状态。

## 设计系统与交付边界

实际绑定为 `ReactSpectrumS2_ad4872`，来源声明 `@react-spectrum/s2@1.6.0`、Tokens `14.15.0`；本地官方 S2 包版本同为 `1.6.0`。已核对 ActionButton 与 Tabs 的来源、按钮事件桥接、Token、键盘行为及本次受影响样式。页面实际加载 `vendor/runtime.js`、`vendor/styles.css`、`vendor/workspace.css`，构建检查确认与可维护源码一致；导入的 S2 绑定与 v0.3.0 基线逐字节一致。

原型使用轻量视觉组件和应用行为封装：复制按钮组合 S2 ActionButton，Tabs 的方向键、选择和面板由原型封装补齐，弹层由现有原生 dialog 实现焦点行为。它们不等同官方 React Aria 生产组件；本轮未更换运行时，也不以封装反向定义 S2。字体允许既有系统回退。

源码分支为 `codex/prototype-v0.4.0-homepage`，实际祖先包含 v0.3.0 `1355bdc4a14197d1d2dfec09e26096446d080be5`。当前 R03 提交记录见任务清单。原型及文档分别在各自仓库本地提交。

身份、Wallet、签名、广播、索引和 Proof 使用确定性样例，不代表生产验证；生产适配继续按核心认知第 12 节执行。素材出处见[素材清单](ownword-prototype/fixtures/homepage/sources.json)。当前唯一下一步为用户视觉复核。
