## 返回按钮审核

审核依据为 OwnWord 四项设计原则、绑定 Spectrum S2 和用户指定的 [frontend-design](../../../.agents/skills/frontend-design/SKILL.md)。baoyu-design 组织预览，react-spectrum 核对实现。

普通按钮的水平内边距让原返回图标框缩进 22px，字重 700 加强了辅助操作。本次共用 BackButton 继续组合 S2 quiet Button 与 ChevronLeft，使用现有图标尺寸、间距、文字和中性表面 Token；字重为 500，图标框对齐内容左边缘。按钮向左扩展 8px 点击区域，保留至少 44px 高度。悬停出现中性背景且位置稳定，键盘焦点轮廓完整可见。

个人主页、名单、阅读、版本、媒体、编辑和 Artifact 顶部入口共用该组合。代理已逐一查看受影响截图：返回操作的层级较轻，英文长标签与中文短标签在 320px 均无溢出，图标与文字垂直居中；页面内容仍为视觉主体。自动测量与代理审核不代表用户批准。

## 实际验证

[R04 浏览器记录](ownword-prototype/evidence/homepage-v040/R04/verification.json)包含 7 类页面、9 份布局记录、10 项导航及运行检查。按记录中的路由，用 agent-browser 独立会话复核桌面与 320px、返回目的地、键盘 Enter、悬停和中文深色状态。所有图标框与内容左边缘及垂直中心误差小于 1px，按钮宽高均至少 44px，页面无横向溢出。

`npm run build`、`./init.sh` 通过，覆盖构建资源新鲜度、继承模型、关系模型、Git 祖先、S2 绑定与资源。浏览器运行异常为空。本轮未重跑全部业务 BDD、全站无障碍或生产验证。

当前整站层级与分组的验证见 [R03 证据](ownword-prototype/evidence/homepage-v040/R03/verification.json)；P01–P10 既有 BDD 见[功能验收汇总](ownword-prototype/evidence/homepage-v040/acceptance.json)，这些既有证据不计作本轮返回按钮检查。

## 设计系统与交付边界

实际绑定为 `ReactSpectrumS2_ad4872`，来源声明 `@react-spectrum/s2@1.6.0`、Tokens `14.15.0`。原型使用继承的轻量视觉组件与应用行为封装，不等同官方生产运行时。本轮保留绑定资源，只在应用层统一返回布局和状态；页面加载预编译资源，构建检查确认其与源码一致。

源码分支为 `codex/prototype-v0.4.0-homepage`，继承 v0.3.0 `1355bdc4a14197d1d2dfec09e26096446d080be5`；原型与任务文档分别在各自仓库本地提交。身份、Wallet、签名、广播、索引和 Proof 使用确定性样例，生产适配按核心认知第 12 节验证。当前唯一下一步为用户视觉复核。
