当前 P01–P10 已实现并验证，原制作验收的 32 条 BDD 对应 81 项实际浏览器断言。当前 R01、R02 已采用常规字级并收紧全页排版；R02 检查 54 个页面及状态，共 108 项桌面与窄屏布局记录，另核对相关交互和短屏弹层。本轮未重跑完整业务 BDD。新版从最新 v0.3.0 源码继续制作，作废的旧 v0.4.0 文件和验收记录已删除。功能及资产保持 `needs-review`，等待用户视觉复核。

需求以[当前版本设计文档](../../system-design/spec/prd/v0.4.0/设计文档v0.4.0-个人主页-20260918.md)和[核心认知](../../system-design/spec/核心认知.md)为准；本文件记录实际产物、证据与交付边界。

## 预览与演练

[打开 Maya Chen 公开主页](http://127.0.0.1:4314/#/identity/2FfJxP9rMWqeBZQ3KxL2wZsLbS7xw8bVpD)，公开浏览无需连接 Wallet。页面可浏览博客、图片、视频、音频，查看身份详情、有效 Current 编号、历史版本、关注列表与粉丝列表。

关系操作使用页脚的原型演练面板：重置为初始或空关系场景，连接样例身份 A（Maya Chen），访问 B（North Studio）并申请好友；在既有 Wallet 场景中切换账户为 B，再访问 A 并接受。确认页显示当前操作身份和目标身份的完整 BAP ID；路由切换只改变浏览目标。

面板可演练读取失败、授权取消、签名身份不匹配、未知提交结果、索引延迟和账户变化。未知提交先查询，索引延迟保留已知状态；关注与好友分别处理。图片可以放大，视频和音频使用实际原生播放控件，离开详情停止播放。

在本任务目录启动：

```sh
./init.sh --serve
```

Windows 使用 `./init.ps1 -Serve`。端口为 `4314`；已运行时直接访问预览。构建与逐项验证命令见[源码 README](ownword-prototype/README.md)。

## 本轮验证

[验收汇总](ownword-prototype/evidence/homepage-v040/acceptance.json)逐项引用十份浏览器记录，覆盖公开路由、内容归属与分页、版本、安全 Markdown、实际媒体播放、双方好友流程、关注人数与方向、名单去重、提交恢复、身份隔离和返回位置。测试使用确定性样例，不沿用旧 v0.4.0 证据。

`./init.sh` 的基线、资源新鲜度、语法、继承模型、新关系模型及 harness 结构检查通过；Markdown 安全渲染检查通过。相关浏览器记录中的运行异常为空。结构检查分数仅评价 harness 完整性，不作为视觉质量或无障碍认证。

当前字级与排版以设计总指南第 3.1 节和本版本设计文档第 4.2 节为准。[R01 实际检查](ownword-prototype/evidence/homepage-v040/R01/verification.json)核对桌面 `1440 × 900`、手机 `390 × 844` 与 `320 × 900`，并实际查看主页、名单、关系确认、阅读、Artifact 和欢迎页的八张截图。主标题和编号不超过 28px，公开列表标题不超过 20px，正文不超过 16px；复制、标签方向键、弹层内焦点及关闭返回保持可用。

当前预览的首条作品起始位置为桌面 563px、390px 手机 650px、320px 手机 674px，手机首屏可见首条标题和摘要。这些值来自当前命中非鼠标输入尺度的浏览器；未据此宣称真实鼠标环境、全部内容长度或输入模式均已验证。既有 S2 源 Token、字体家族与业务流程保持继承。

全页结果见 [R02 检查记录](ownword-prototype/evidence/homepage-v040/R02/verification.json)，复现命令为 `node verify-layout.mjs`。覆盖欢迎、偏好与导航，公开身份与名单，阅读、版本和媒体，身份设置与编辑、确认、授权、结果与错误，草稿、编辑模式、发布与离开保护，以及 Artifact 管理、关联、转移、创建、历史与查找。54 个页面及状态在 `1440 × 900` 和 `320 × 900` 下检查字号和控件边界；另查身份、查找与阅读的中文深色，以及 `320 × 568` 关系确认弹层。当前记录中的大字号、页面横向溢出和越界控件为空，浏览器运行异常为空。

截图审阅后修复：手机编辑器操作换行和正文过晚出现，身份页内边距及标识换行，确认页长姓名过度折行，共用弹层的大标题与标识字号，隐藏预览后的 Artifact 双列空位，以及手机规则对紧凑间距的覆盖。已查看全部 54 份手机页面与状态截图、六份桌面重点截图和短屏弹层截图。手机编辑器正文起始位置由约 491px 提前至 405px；[修订前记录](ownword-prototype/evidence/homepage-v040/R02/before/measurements.json)用于定位原布局问题。

相关操作实际走通：身份编辑与创建的确认、样例授权及取消，内容编辑、离开保护、样例发布与阅读，Artifact 关联取消、转移确认和样例创建。音频实际播放及离开后停止通过检查，短屏弹层保留可达的主要操作、Tab 焦点和 Escape 返回。源码与预编译资源、Git 基线及继承模型检查通过。

## 复核与生产边界

当前待用户复核页面层级、密度、内容呈现和关系操作体验。键盘验证覆盖标签方向键、焦点可见、弹层内循环及关闭后返回。全页检查覆盖记录中列出的页面与状态，不扩展为全部数据长度、输入设备或主题语言组合；本轮未执行全站屏幕阅读器或 axe 审计，也未重跑 v0.3.0 全量业务 BDD。

身份、Wallet、签名、交易广播、索引和 Proof 为确定性模拟，未调用真实钱包或生产 API；通信公钥未在原型中派生。生产 Friend 协议、签名归并与媒体适配继续按核心认知第 12 节验证。媒体文件实际可播放，出处、许可与摘要见[素材清单](ownword-prototype/fixtures/homepage/sources.json)。

原型继承既有 S2 轻量消费运行时，生产实现须使用绑定版本的官方组件与交互能力。源码和任务记录已在各自本地仓库提交，本轮未推送远端。
