## 实际验证

[R05 浏览器记录](ownword-prototype/evidence/homepage-v040/R05/verification.json)包含 5 份列表布局记录、手机首屏位置，以及 12 项交互与运行检查。常规列表视口为 1440×900 和 320×900；另核对 320×720 首屏。按记录中的路由、操作与临时样例方式使用 agent-browser 独立会话复核。

- 四类内容顺序、统一尺寸、标题两行上限、文字对齐与点击区域通过检查，页面无横向溢出。
- 类型筛选、End/Home、键盘进入视频及实际播放、返回后的加载结果与滚动位置通过检查。
- 长标题与损坏预览通过独立浏览器中的临时模型覆盖模拟；失败窗口保持尺寸，仍能进入原始作品详情。没有改写持久化样例或链上记录。
- `npm run build`、`./init.sh` 通过，覆盖构建新鲜度、继承模型、关系模型、Git 祖先、S2 绑定与资源。
- [中文深色主页 axe](ownword-prototype/evidence/homepage-v040/R05/accessibility.json)为 0 violations、0 incomplete；浏览器运行异常为空。

本轮未重跑全部业务 BDD、全站无障碍或生产验证。共用返回入口的既有检查见 [R04](ownword-prototype/evidence/homepage-v040/R04/verification.json)，整站信息层级见 [R03](ownword-prototype/evidence/homepage-v040/R03/verification.json)，既有功能 BDD 见[功能验收汇总](ownword-prototype/evidence/homepage-v040/acceptance.json)；既有证据不计作本轮检查。

## 设计系统与交付边界

实际绑定为 `ReactSpectrumS2_ad4872`，来源声明 `@react-spectrum/s2@1.6.0`、Tokens `14.15.0`。列表复用现有 S2 Link、Tabs、图标、字体、颜色、间距和圆角；预览尺寸属于当前 PRD 的应用布局约束。原型使用继承的轻量视觉组件及应用行为封装，不等同官方生产运行时。页面加载预编译资源，构建检查确认其与源码一致。

源码分支为 `codex/prototype-v0.4.0-homepage`，继承 v0.3.0 `1355bdc4a14197d1d2dfec09e26096446d080be5`；原型与任务文档分别本地提交。身份、Wallet、签名、广播、索引和 Proof 使用确定性样例，生产适配按核心认知第 12 节验证。当前唯一下一步为用户视觉复核。
