# v0.4.0 设计审查

审查时间：2026-10-02 21:22:35，Asia/Shanghai。依据为[核心认知](../../system-design/spec/核心认知.md)、[设计指南](../../../standard/OwnWord设计与设计系统.md)和[v0.4.0 PRD](../../system-design/spec/prd/v0.4.0/设计文档v0.4.0-个人主页-20260918.md)。这是当前范围、结构与视觉方案的审查，不代表视觉验收或获奖认定。

## 结论

现有 v0.3.0 基线已具备身份卡、数字 ID 状态、公开阅读和作者入口。v0.4.0 复用这些能力，以 BAP ID 聚合已发布内容，使用独立地址承载个人网站。当前视觉方案采用 high-end-visual-design 的 Soft Structuralism 与 Editorial Split：左侧大字作者介绍、右侧双层文章卡片、悬浮胶囊导航，手机转为单列。Ownword 平台标识位于页脚，身份记录按需展开。搜索结果的姓名与主页入口在新标签页打开，原搜索结果保留。

按 PRD 六项范围逐项实施：公开主页状态、Identity Hero、身份卡片、内容展示、阅读入口、版本关联。P01 先接通数据和恢复路径，P02–P04 整理展示品质，P05–P06 完成阅读连续性与版本验收。具体依赖和完成条件只维护在 `feature_list.json`。

## 设计约束

- BAP ID 是身份根，内容通过 `authorBapId` 关联；公开列表排除草稿并隔离作者，已发布文章保持只读。
- 首屏先解释作者和公开身份，再进入内容；页面没有工作区管理导航，访客无需连接钱包。身份信息、发布记录与内容版本各有明确归属，不把模拟状态呈现为真实链上证明。
- 沿用已有 Dome & Horizon 视觉和 S2 绑定 `ReactSpectrumS2_ad4872`。当前资源是轻量运行时消费副本，对应 `@react-spectrum/s2@1.6.0`、`@adobe/spectrum-tokens@14.15.0`；不升级、不修改 `_ds`。
- 保留 S2 字体、图标、Token 与标准控件，展示层应用指定技能的构图、双层容器、嵌套阅读图标和自定义曲线动效。入场使用 IntersectionObserver，仅动画 transform 与 opacity；减少动态效果时停用。
- R03 已实际验证桌面、手机、中文深色、键盘阅读、焦点返回与失败恢复，详见功能清单所引证据。此轮未重复旧版全部验证矩阵。
