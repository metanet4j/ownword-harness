ADR 保存架构决策的背景、选择、后果和验证门槛，不充当产品事实或代替[核心认知](../核心认知.md)。仅当决定产生影响时创建 ADR；独立文件按项目时间戳命名。已批准的决策需要变更时，新建后续 ADR 并在入口更新当前生效关系，不追加流水式修改历史。
