## 已核实的范围与实现缺口

v0.4.0 原型已包含 Follow、好友申请/接受、公开关注与粉丝；尚没有经生产验证的完整 Friend 授权与重组恢复契约。

**实现前必须核实**：Relationship 端点使用 BAP ID；单方 Friend 不能认定双方已成立，拒绝/撤销等未确定的协议功能保持待验证。

当前不可凭空生成新的领域字段、API 或正式验收结果；后续新增带时间戳的领域设计文件并在本入口引用。审批前保持 needs-review。
