# 区块链身份与内容平台设计

> **Own your identity. Own your words.**
> 拥有你的身份，为你的言论负责。

------

## 术语

### Wallet

用户控制私钥、资产和签名能力的钱包。

MVP：

- Yours Wallet

原则：

- 平台不保存私钥
- 平台不代替用户签名
- 钱包接入必须抽象，支持未来扩展其他钱包

### BAP Identity

基于 BAP 协议的区块链身份。

核心标识：

- BAP ID

BAP ID 是稳定身份标识，不作为普通资料修改。

### BAP NFT

基于 1Sat Ordinals 创建的身份 NFT。

规则：

- 系统允许创建多个 BAP NFT
- 同一个 BAP ID 同时最多绑定 1 个 BAP NFT
- BAP NFT 不等于 BAP Identity
- BAP NFT 不作为身份认证依据

### Profile

BAP Identity 的展示资料。

包括：

- 名称
- 头像
- 简介
- 网站
- 社交链接

Profile 可修改，BAP ID 不变。

### Content

用户发布的链上内容。

MVP：

- Markdown

主要采用：

- BitcoinSchema/schema
- B Protocol
- MAP
- AIP

### Relationship

BAP Identity 之间的关系。

优先采用 BitcoinSchema 已有定义，例如：

- Follow
- Unfollow
- Friend
- Reply
- Repost

------

# 目标

建立一个基于区块链的：

**身份 + 关系 + 内容平台。**

核心理念：

### 身份属于用户

身份由用户的钱包和密钥控制，而不是平台账户控制。

### 内容属于用户

用户决定发布什么内容，并通过自己的身份签名。

### 内容责任属于用户

每条正式发布的内容都能够验证：

- 谁发布
- 发布了什么
- 是否被修改
- 对应哪笔链上交易

### 平台不是权威

平台提供：

- 身份管理界面
- 内容编辑
- 协议解析
- 数据索引
- 内容验证
- 社交关系展示

身份和内容真实性不依赖平台数据库。

------

# 关系

核心关系：

```text
Wallet
  │
  └── controls
        │
        ▼
    BAP Identity
        │
        ├── Profile
        │
        ├── Content 1..N
        │
        ├── Relationship 0..N
        │
        └── BAP NFT 0..1（绑定）
```

BAP NFT：

```text
系统
│
└── BAP NFT 0..N

BAP ID
│
└── Bound BAP NFT 0..1
```

即：

> NFT 可以创建多个，但一个 BAP ID 同一时间只能绑定其中一个。

Identity 与 Content：

```text
1 Identity
    │
    └── N Content
```

Identity 与 Identity：

```text
Identity
   │
   ├── Follow
   ├── Friend
   ├── Reply
   └── Repost
   │
   ▼
Identity
```

优先使用 BitcoinSchema 已有关系定义。

# 界限

## 1. 钱包

业务层不直接依赖 Yours Wallet。

```text
WalletPort
    │
    ├── YoursWalletAdapter
    └── OtherWalletAdapter
```

------

## 2. 私钥

平台永远不：

- 保存私钥
- 保存助记词
- 服务端替用户签名

------

## 3. 身份

BAP 是身份标准。

平台不重新定义身份协议。

------

## 4. 内容

BitcoinSchema 是主要内容协议。

优先使用：

- B
- MAP
- AIP
- Social Schema

平台不重复设计已有协议。

------

## 5. NFT

1Sat Ordinals 用于：

- BAP NFT
- 数字资产

NFT 不等于身份本身。

BAP 身份认证仍然以 BAP 和密钥关系为准。

------

## 6. 链上数据

已经确认的数据：

- 不修改
- 不物理删除

内容更新通过新交易表达。

------

## 7. 数据库

数据库只用于：

- 缓存
- 索引
- 搜索
- 草稿
- UI 状态

不能作为：

- 身份真实性来源
- 内容真实性来源

------

## 8. MVP

第一版只完成：

```text
Connect Wallet
↓
Create / Load BAP Identity
↓
Create / Bind BAP NFT
↓
Write Markdown
↓
Preview
↓
Sign
↓
Publish
↓
Verify
```

暂不做：

- 推荐算法
- 私信
- DAO
- Token Economy
- NFT Marketplace
- Reputation System
- 复杂社交关系
- 多链
