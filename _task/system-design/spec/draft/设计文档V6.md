# Ownword 产品设计 V7

> Own your identity. Own your words.
>
> 拥有身份，为言论负责。

## 0. 文档定位

本文件定义 Ownword MVP 的产品体验、页面、组件、流程和验收。全局术语、目标、实体、属性、关系、状态和边界，以 [`核心认知.md`](./核心认知.md) 为唯一事实源。

规则冲突时，按以下顺序处理：

1. 协议或可执行 API 的实际约束；
2. [`核心认知.md`](./核心认知.md)；
3. 本文件的页面与交互约定；
4. 原型中的临时表达。

本文件不重复定义核心认知中的实体属性和全局不变量。新增跨模块事实，先写入核心认知，再在本文件引用。

规范词：

- **必须/禁止**：不可偏离的约束。
- **应该**：默认实现；偏离时记录原因。
- **可以**：可选能力。

## 1. 产品体验范围

核心产品定义、目标、术语和全局不变量见 [`核心认知.md`](./核心认知.md) 第 1 至 4 节。本文件只把这些认知落到页面、组件和用户流程。

V6 页面覆盖：

```text
Wallet / Identity / Content / Identity Artifact / Explorer
```

MVP 只实现 `Post + Markdown + UTF-8`；Reply、Repost、Follow、Friend、Message、Tag、Attachment、Attestation 等后续能力不在本版本页面范围内。后续协议能力遵循核心认知第 6 节。

## 2. 体验原则

### 2.1 先目标，后协议

普通用户看到：

```text
Connect Wallet
Create Identity
Write
Publish
Create Artifact
```

协议细节默认放入 Details 或 Proof；术语和披露层级遵循核心认知第 2 节：

```text
BAP / B / MAP / AIP / Ordinal / Origin / Outpoint / BEEF
```

页面不得要求用户先理解协议，才能完成基本操作。

### 2.2 三个确定性

每个高影响操作都要让用户知道：

1. 当前使用哪个 Identity；
2. 当前执行哪一步；
3. 业务结果是什么；
4. 链上状态是什么；
5. 失败或取消后下一步是什么。

统一流程：

```text
User Intent
  -> Review
  -> Wallet Confirmation
  -> Processing
  -> Business Result
  -> Blockchain Details
```

### 2.3 主标识

主标识不得降级为隐藏协议细节。具体定义和不变量见核心认知第 2、4 节；V7 只规定页面层级：

| 对象 | 首要标识 | 用途 |
| --- | --- | --- |
| Identity | `BAP ID` | 展示、复制、精确查找、Relationship 端点 |
| Artifact | `Inscription Number` | 展示、复制、精确查找 |
| Proof / Debug | `Inscription ID`、`Ordinal Number`、`Origin`、`Current Outpoint` | 精确验证、故障排查 |

页面可以缩略长值，但 Copy 必须返回完整原值。

## 3. 信息架构与模块

### 3.1 页面模块

横切能力：

```text
Internationalization

Proof / Transaction Tracking / Error Semantics
```

页面关系：

```text
                  Wallet
                    |
                    v

                /    |    \
               v     v     v
            Content Artifact Relationship
```

具体依赖和边界遵循核心认知第 4、5、10 节。

### 3.2 页面与领域接口

页面组件通过领域接口取得数据；禁止在组件中直接调用 Yours Wallet API。接口职责和适配边界遵循核心认知第 5 节：

```text
业务组件
  -> 领域接口
  -> Yours Wallet Adapter / Indexer Adapter
```

| 接口 | 页面用途 |
| --- | --- |
| `WalletProvider` | 连接状态、账户变化和 Wallet 授权 |
| `IdentityProvider` | Identity 解析、Profile、Rotation |
| `ContentProtocol` | Post 编码、签名和发布 |
| `OrdinalProvider` | Artifact 查询、创建和 Transfer |
| `BlockchainIndexer` | Artifact 编号和交易状态展示 |
| `IdentifierResolver` | Lookup 结果展示 |

`inscribe` 返回交易信息；编号展示遵循核心认知第 4、5 节，确认前不得显示猜测值。

### 3.3 页面数据边界

页面可展示 Draft、缓存、搜索索引和交易跟踪。链上事实、派生数据和用户 Wallet 数据的权威来源不在 V6 重复定义，统一引用核心认知第 5、10 节。

### 4.2 标识展示与复制

`BapIdDisplay`：

- Identity Detail 默认显示完整 BAP ID；紧凑列表可以中间省略。
- Copy 始终复制完整值。
- 复制成功显示 `Copied`，不改变布局。
- 复制失败保留原值，并显示 `Couldn't copy`。

`InscriptionNumberDisplay`：

- 已确认时显示 `#165`；Copy 返回原始字符串 `165`。
- 搜索接受 `165` 和 `#165`，两者解析同一 Artifact。
- 未确认时显示 `Pending confirmation`，不显示占位编号。
- reorg 后允许重新解析，并显示 `Inscription Number changed after chain reorganization.`

图标按钮必须有可访问名称。签名状态使用 `Signature valid` 或 `Signed by this identity`；术语禁区遵循核心认知第 2.3 节。

### 4.3 文案与状态

所有产品文案使用 i18n key，禁止组件内散落硬编码中英文。

| 场景 | 标准文案 |
| --- | --- |
| 连接 | `Connect Wallet` |
| 创建 Identity | `Create Identity` |
| 修改 Profile | `Save Changes` |
| 写作 | `Write` |
| 审核 | `Review` |
| 发布 | `Sign & Publish` |
| 创建 Artifact | `Create Artifact` |
| 设置当前 | `Set as Current` |
| 更换 | `Change Artifact` |
| Rotation | `Rotate Key` |
| 重试 | `Try Again` |
| 复制 | `Copy` |

底层动作只在 Details 或 Proof 展示；操作命名遵循核心认知第 2.3 节。

用户状态保持短、可解释：

```text
Not connected / Connecting / Connected
Connection cancelled / Connection failed
Creating identity... / Identity ready
Saving... / Saved
Publishing... / Published
Creating artifact... / Artifact created
Resolving identity... / Indexing inscription...
```

取消不是失败：

```text
Publishing cancelled
Your draft is unchanged.
```

失败必须说明发生了什么、影响什么、下一步做什么：

```text
Couldn't publish
Your draft is safe. No content was published.
[Try Again] [Back to Editor]
```

### 4.4 国际化、主题、无障碍

稳定约束遵循核心认知第 4、10 节。V6 只定义实现和验收关注点：

- 文案由 i18n key 提供，默认显示英文，可切换 `zh-CN`。
- 设置页提供 `light`、`dark`，组件只使用语义 Token。
- 日期、长文案、CJK 字体、窄屏和错误状态纳入页面验收。
- 状态同时使用文字或图标表达，不依赖颜色。

建议 Token：

```text
canvas / surface / surface-raised
text-primary / text-secondary / border
action / metal-accent / focus-ring
status-success / status-warning / status-error
```

### 4.5 视觉方向

视觉表达服务于 Identity、Signature、Proof、Metal、Artifact、Ledger 和 Territory。

总体方向：

```text
重量感 / 新大陆感
```

禁止 Crypto Casino、Cyberpunk、Neon 风格。建议使用 Steel、Titanium、Graphite、Silver、Engraving、Stamp、Seal 等材料和工艺隐喻，传达分量、责任、稳定和可验证性。

Identity 采用 `Metal Identity Plate` 方向：

```text
ALICE

BAP ID 8F3...K91
IDENTITY
```

Content 采用 `Signed Statement` 方向，在正文末尾展示：

```text
SIGNED BY
Alice
BAP ID 8F3...K91
Signature valid
```

Artifact 可以表现为 Seal、Badge、Metal Card 或 Medal，不采用 NFT Marketplace Card 作为默认隐喻。任何视觉表达都不得把密码学签名写成现实世界身份认证。

响应式布局：

| 视口 | 默认布局 |
| --- | --- |
| Desktop | Content、Identity、Proof 可并列展示 |
| Mobile | 先显示 Identity 和 Content，Proof 收入 `View Proof` |

窄屏统一缩略长标识，例如 `8F3a...91Bc`、`abcd...7890`；点击后提供 Copy 和 View full。完整值始终保留在可复制数据中。

## 5. MVP 用户流程

### 5.1 连接 Wallet

用户看到：

```text
Connect Wallet
  -> Connecting...
  -> Connected
```

多 Wallet 时增加：

```text
Connect Wallet
  -> Choose Wallet
  -> Connecting...
  -> Connected
```

`Detecting`、`Selecting`、Provider discovery 属于系统状态，不直接暴露给普通用户。状态映射遵循核心认知第 9.1 节。

#### Account Switch

账户变化时按固定顺序处理：

```text
Account changed
  -> Cancel pending sensitive action
  -> Clear old Identity context
  -> Resolve new Identity
  -> Update UI
```

以下状态必须触发页面取消反馈：`Review Publish`、`Awaiting Signature`、`Creating Artifact`、`Rotating Key`。账户切换规则遵循核心认知第 10.1 节。

提示：

```text
Wallet account changed
The previous action was cancelled.

Current identity:
Bob
BAP ID 91A...232 [Copy]
```

依据：Yours Wallet Provider API 的 `useWallet()`、`switchAccount`、`signedOut` 和 `identityKey`。

### 5.2 创建、查看和维护 Identity

连接后系统执行：

```text
computeBapId
  -> resolveBapId
```

普通用户不需要看到函数名。自动分流：

| 解析结果 | 下一步 |
| --- | --- |
| Identity 已发布、Profile 完整 | `My Identity` |
| Identity 未发布 | `Set Up Identity` |
| Identity 已发布、Profile 不完整 | `Complete your profile` |

不要求用户自行判断 `Create Identity` 或 `View Identity`；分流由应用完成。

#### Identity Setup

用户体验合并 Identity 发布和 Profile 创建；领域操作仍独立：

```text
Set up your identity
  -> Profile
  -> Review
  -> Create Identity
  -> Wallet Confirmation
  -> Creating...
  -> Identity Ready
```

Profile 字段：`Avatar`、`Name`、`Person / Organization`、`Bio`。

Review 显示当前 Profile、BAP ID 和 `Your wallet controls this identity.`；完整标识按核心认知第 4 节提供复制：

```text
Create your identity

Alice
Person
Building independently on Bitcoin.

BAP ID 8F3...K91 [Copy]
Your wallet controls this identity.

[Back] [Create Identity]
```

成功页：

```text
Your identity is ready
Alice
BAP ID 8F3...K91 [Copy]
[Go to My Identity]
```

#### Identity Home 与 Public Identity

首屏主信息层级显示 Avatar、Name、完整或可缩略 BAP ID、Type、Bio。BAP ID 不得藏在 Proof、菜单或折叠区。

页面入口：

```text
Words / Artifacts / Relationships
```

没有 Artifact 时，页面仍显示 Write、Publish 和 Lookup 入口；能力边界遵循核心认知第 4 节。

#### Profile 修改

允许修改 `Avatar`、`Name`、`Description/Bio`、`Type`：

```text
Edit Profile
  -> Save Changes
  -> Wallet Confirmation
  -> Saving...
  -> Saved
```

#### Identity Security 与 Key Rotation

入口：`Identity -> Settings -> Identity Security`。MVP 提供 `Rotate Key`；Attestation 和 Revoke 留作后续。

```text
Rotate Key
  -> Review
  -> Wallet Confirmation
  -> Rotating...
  -> Completed
```

Review 明确显示：`Your BAP ID will not change.`；Rotation 规则遵循核心认知第 4、9.2 节。

### 5.3 Identity Lookup

查找入口可放在 Header、Explore 和 Relationship Picker：

```text
Find an identity
[ BAP ID or Inscription Number ]
[Search]
```

解析规则：

```text
BAP ID
  -> Resolve published BAP Identity

Inscription Number
  -> Resolve Inscription
  -> Resolve Artifact Origin
  -> Resolve Current Binding
  -> Resolve BAP Identity
```

结果页始终突出最终 BAP ID。Artifact 无有效 Binding 时显示 Artifact 本身与：

```text
No identity is currently associated with this artifact.
```

不得把 Artifact owner、creator 或 signer 自动当作关联 Identity。Relationship 复用此查找流程，但链上关系端点始终保存稳定 BAP ID，不保存可能随 reorg 变化的 Inscription Number。

### 5.4 Words 创建与发布

MVP 固定：`Post + Markdown + UTF-8`。输入方式：直接编辑 Markdown 或导入 `.md`。

#### Write

```text
Write

Signing as
Alice
BAP ID 8F3...K91 [Copy]

[WRITE] [PREVIEW]
# Title        Title
               Rendered Markdown

[Import Markdown]
Draft saved
[Review]
```

Editor 只负责 Write、Preview、Draft、Review，不展示 `Broadcast`、`Submit Transaction`、`Push TX`。

#### 内容协议

MVP 使用 BitcoinSchema Post：

```text
B + MAP + AIP

B:   content + media type + encoding
MAP: type=post, app=<application>
AIP: author signature

mediaType = text/markdown
encoding  = UTF-8
```

具体字段、编码和签名以 [`核心认知.md`](./核心认知.md) 及本地 Social Schema 为准。

#### Publish Review

```text
Review your words

Signing as
Alice
BAP ID 8F3...K91 [Copy]

Content Preview
Format   Markdown / UTF-8
Protocol BitcoinSchema Post

This version will become public and permanent.

[Back] [Sign & Publish]
```

首次发布可说明：已发布版本进入公开 Bitcoin 记录；后续只能发布新 Revision，原版本继续存在。无需增加强制勾选。

#### Wallet、取消与发布结果

`Sign & Publish` 打开 Wallet 授权；Wallet Confirmation 不是本站独立页面。

用户关闭 Wallet 或拒绝：

```text
Publishing cancelled
Your draft is unchanged.
[Back to editor]
```

授权后显示 `Publishing...`。内部可执行 Sign、Broadcast、Network acceptance、Index；用户不必理解步骤。

交易广播并被网络接收后：

```text
Published
Transaction broadcast
Confirmation pending
Transaction abcd...7890 [Copy]

[Read Post] [View Transaction]
```

产品状态与链状态分开：

```text
产品：Draft -> Publishing -> Published
链上：Broadcast -> Seen -> Accepted -> Mined -> Immutable
```

实际 Wallet/Indexer 枚举必须映射到产品语义。未挖矿不等于发布失败。

#### Revision

已发布内容不显示 `Edit`，只显示 `Create Revision`：

```text
Published V1
  -> Create Revision
  -> Draft V2
  -> Review
  -> Sign & Publish
  -> Published V2
```

旧版本保持公开。每个 Revision 生成新链上版本和新 Transaction。

### 5.5 Identity Artifact

领域实体名为 `BapNFT`，用户侧统一称 `Identity Artifact`。它是与 BAP Identity 关联的 1Sat Ordinal，用于视觉化和资产化表达；它不是 Identity，也不阻塞 Content。

#### 入口与创建

Identity Home 无 Artifact 时：

```text
Identity Artifact
No artifact yet.
Create a visual artifact for your identity.
[Create Artifact] [Skip]
```

创建流程：

```text
Create Artifact
  -> Choose Content
  -> Preview
  -> Review
  -> Wallet Confirmation
  -> Creating...
  -> Transaction broadcast
  -> Created
  -> Set as Current automatically
```

Review 必须显示当前 Identity、完整 BAP ID、Artifact 预览，以及：

```text
Inscription Number
Assigned after confirmation
```

`inscribe` 页面显示 BAP identity signing、Artifact 预览和编号待确认状态；具体字段、签名封装和 Binding 规则遵循核心认知第 6、7、10 节。

#### 标识层级

Artifact Detail 首屏突出 Inscription Number 和 Associated Identity；Details/Proof 展示：

```text
Inscription Number  #165 [Copy]
Associated Identity Alice
BAP ID              8F3...K91 [Copy]

Inscription ID      e17d...a584_1 [Copy]
Ordinal Number      <decimal string> [Copy]
Origin              e17d...a584_1 [Copy]
Current Outpoint    5af8...f2ba_0 [Copy]
```

确认前只显示 `Pending confirmation`；编号异常时允许刷新并提示：

```text
Inscription Number changed after chain reorganization.
Please verify the current value.
```

Details/Proof 保留四个协议标识的独立展示；定义遵循核心认知术语表。

#### Binding 与多个 Artifact

创建成功后默认尝试：

```text
Create Artifact
  -> Set as current Identity Artifact
```

领域模型仍将 Artifact 与 Binding 分开。页面展示多个 Artifact 的产品状态：

```text
Artifact A  Historical
Artifact B  Current
Artifact C  Not used
```

普通用户看到 `Current Identity Artifact`、`Set as Current`、`Change Artifact`，不看到系统枚举。

#### Transfer 与失效

Transfer 和 Binding 校验必须遵循核心认知第 10.4 节。页面只负责展示结果和下一步。

所有权或 Origin 校验失败时显示：

```text
Identity Artifact unavailable
This artifact has changed ownership and can no longer be used as your current identity artifact.
[Choose Another Artifact] [Remove Association]
```

页面必须说明发生了什么、影响什么、用户能做什么。Artifact body、MAP metadata、Ownership 分开展示和处理。

### 5.6 领域模型索引

V6 使用以下核心实体；定义、属性约束和不变量统一引用 [`核心认知.md`](./核心认知.md)：

| 实体 | V6 用途 |
| --- | --- |
| `WalletConnection` | 保存当前 Wallet 会话和账户上下文 |
| `BAPIdentity` | 作为所有 Identity 操作的主体 |
| `BAPProfile` | 展示和修改 Identity 信息 |
| `Content` | 保存 Draft 或已发布 Post |
| `ContentRevision` | 追加已发布内容的新版本 |
| `BapNFT` | 表示 Identity Artifact 的 1Sat Ordinal |
| `IdentityNFTBinding` | 表示 Identity 与 Artifact 的独立关联 |
| `Relationship` | 保存 BAP ID 到 BAP ID 的关系 |
| `BlockchainTransaction` | 跟踪 Identity、Content、Artifact 和 Key Rotation 交易 |

唯一来源：

```text
实体与属性  -> 核心认知.md 第 7 节
关系        -> 核心认知.md 第 8 节
状态        -> 核心认知.md 第 9 节
界限        -> 核心认知.md 第 10 节
```

## 6. 状态展示

状态机唯一来源是 [`核心认知.md`](./核心认知.md) 第 9 节。V6 不复制状态转移，只规定页面映射：

- 页面显示产品语义，不直接暴露 SDK 或 Indexer 枚举；
- Content 的业务状态和链上确认状态分开显示；
- `Cancelled` 表示用户取消，`Failed` 表示系统失败；
- `Pending confirmation`、`Unavailable`、`Historical` 等非失败状态必须提供解释。

## 7. MVP 原型与主路径

### 7.1 页面清单

```text
Landing
Connect Wallet
Wallet Connecting / Failed
Identity Auto Resolution
Identity Setup / Review / Creating / Ready
My Identity / Public Identity
Edit Profile / Identity Security
Identity Lookup by BAP ID / Inscription Number
Write / Markdown Preview
Publish Review / Publishing / Cancelled / Failed
Published Post / Public Post / Content Proof
Create Artifact / Preview / Creating / Detail
Change Current Artifact / Invalid Artifact Association
Language: English / 中文
Theme: Light / Dark
```

Wallet Authorization 不设计成本站独立页面。

### 7.2 主路径

首次使用：

```text
Landing
  -> Connect Wallet
  -> Wallet Authorization
  -> Resolve Identity
  -> Set Up Identity
  -> Review
  -> Create Identity
  -> Wallet Confirmation
  -> Creating...
  -> Identity Ready
  -> My Identity
```

已有用户：

```text
Connect Wallet
  -> Resolve Identity
  -> Identity exists
  -> My Identity
```

Identity Home 平行入口：

```text
My Identity
  +-- Write
  +-- Artifact
```

全局入口：

```text
Header
  +-- Language: English / 中文
  +-- Theme: Light / Dark
  +-- Find Identity: BAP ID / Inscription Number
```

发布：

```text
Write -> Preview -> Review -> Sign & Publish -> Wallet -> Publishing -> Published -> Public Post
```

Artifact：

```text
My Identity -> Create Artifact -> Preview -> Review -> Wallet -> Creating -> Created
  -> Inscription Number pending confirmation
  -> Indexer confirms
  -> Inscription Number #<number>
```

## 8. 可验证验收

以下验收覆盖 V6 主路径和新增要求；实体、属性、状态、边界验收同时遵循 [`核心认知.md`](./核心认知.md) 第 11 节。

### 8.1 Identity 与 Lookup 页面

```text
Given 用户打开 Identity Lookup
When 输入完整 BAP ID 并搜索
Then 页面显示 Identity 结果和 Copy 反馈

Given 用户打开 Artifact Lookup
When 使用 165 或 #165 搜索
Then 页面显示同一 Artifact 和关联 Identity

Given Lookup 返回 Artifact 但没有有效 Binding
When 使用 Inscription Number 搜索
Then 返回 Artifact，但显示 No identity is currently associated with this artifact.
```

### 8.2 Artifact 页面状态

```text
Given Artifact 交易尚未确认
When 打开 Artifact Detail
Then 显示 Pending confirmation，不显示猜测编号

Given Artifact 已获得 Inscription Number
When 点击 Copy
Then 剪贴板得到原始十进制字符串，不是 # 前缀、缩略值或本地化格式

Given 页面显示缩略 BAP ID、TxID 或 Outpoint
When 点击 Copy
Then 剪贴板得到完整原值

Given Indexer 返回编号变化或 Binding 不可用
When 打开 Artifact Detail
Then 页面显示解释性状态和下一步操作
```

### 8.3 Wallet、Identity、Content 页面

```text
Given Wallet 拒绝发布
When 应用收到取消结果
Then 状态为 Publishing cancelled，Draft 保持不变，不显示系统 Failed

Given 交易已广播但仍等待确认
When 打开结果页
Then Content 为 Published，同时显示 Confirmation pending

Given 用户在 Published Content 点击修改
When 用户保存
Then 创建新 Revision 和新 Transaction，旧版本继续可访问

Given Account Switch 发生在任一高影响操作中
When 应用收到事件
Then 取消旧操作、清除旧 Identity context、解析新 Identity

Given 页面展示 Key Rotation 结果
When 用户返回 Identity
Then 页面显示 BAP ID 未改变
```

### 8.4 国际化、主题、可访问性页面

```text
Given 没有已保存 locale
When 首次打开应用
Then 产品文案为英文

Given 用户切换到中文
When 页面重新加载
Then 中文页面文案和用户选择保留

Given 用户切换 Light / Dark
When 页面重新加载
Then 主题偏好保留，页面无文字重叠

Given 状态为成功、警告或失败
When 仅关闭颜色感知
Then 仍能通过文字或图标识别状态
```
