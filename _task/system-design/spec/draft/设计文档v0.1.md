# Ownword 产品设计 v0.1

> Wallet / Identity / Theme / Internationalization

## 0. 文档定位

本文指导 v0.1 原型设计和功能实现，只定义产品范围、页面结构、组件拆分、交互状态和 BDD 验收。

全局术语、实体、属性、关系、状态和边界以 [`核心认知.md`](./核心认知.md) 为唯一事实源。本文不定义 API 接口、数据流、数据库或协议实现。

## 1. 版本目标

v0.1 建立 Ownword 最小身份闭环：

```text
Connect Wallet
  -> Resolve Identity
  -> Create or Open Identity
  -> View and Maintain Identity
```

用户完成本版本后，能够：

1. 连接 Yours Wallet；
2. 创建或打开当前 Wallet 控制的 BAP Identity；
3. 查看和修改 Profile；
4. 复制完整 BAP ID；
5. Rotate Key，并确认 BAP ID 不变；
6. 切换英文或中文；
7. 切换 Dark 或 Light 主题。

## 2. 范围

### 2.1 本版本功能

```text
Wallet
  Connect / Cancel / Retry / Disconnect / Account Switch

Identity
  Auto Resolution / Setup / Review / Create
  My Identity / Public Identity / Edit Profile / Rotate Key
  BAP ID Display and Copy

Preferences
  English / 中文
  Dark / Light
```

### 2.2 非目标

以下能力不进入 v0.1：

```text
Identity Artifact
Content
Explorer and global search
Relationship
Attestation
Messaging
```

v0.1 不提供任意 BAP ID 搜索。系统只解析当前 Wallet 对应的 Identity；通用 Identity Lookup 属于 v0.4。

## 3. 全局产品规则

本版本所有页面遵守核心认知第 2、4、9、10 节。页面实现重点：

- Wallet Connection 不称为注册或登录账号；
- 当前操作必须显示明确 Identity；
- BAP ID 在 Identity 页面使用主信息层级；
- 长标识可以缩略，Copy 始终复制完整值；
- Wallet 授权取消显示 `Cancelled`，系统异常显示 `Failed`；
- Account Switch 终止当前敏感操作，并重新解析 Identity；
- Identity 创建和 Key Rotation 遵循 Review、Wallet Confirmation、Processing、Result；
- Locale 和 Theme 只改变界面，不改变 Identity 或链上事实。

## 4. 导航与页面结构

### 4.1 全局导航

Desktop：

```text
Header
  +-- Ownword
  +-- My Identity
  +-- Wallet Status
  +-- Language
  +-- Theme
  +-- Account Menu
```

Mobile：

```text
Header
  +-- Ownword
  +-- Wallet Status
  +-- Menu
        +-- My Identity
        +-- Language
        +-- Theme
        +-- Disconnect
```

连接前只显示 Brand、Language、Theme 和 `Connect Wallet`。连接后显示 Wallet Status 和 My Identity。

### 4.2 页面清单

| 页面 | 目的 | 主要入口 |
| --- | --- | --- |
| Welcome | 连接 Wallet，说明 Identity 归用户控制 | 首次访问、Disconnect 后 |
| Wallet Connection | 展示连接中、取消、失败和重试 | Welcome |
| Identity Resolution | 解析当前 Wallet Identity，完成自动分流 | Wallet 连接成功、Account Switch |
| Identity Setup | 填写 Profile | 未发布 Identity |
| Identity Review | 核对 Identity 和公开信息 | Identity Setup |
| Identity Creating | 展示创建进度、取消和失败 | Identity Review |
| Identity Ready | 展示创建成功 | Identity Creating |
| My Identity | 查看当前 Identity 和版本内操作入口 | Header、创建成功 |
| Public Identity | 展示可公开查看的 Identity Profile | My Identity |
| Edit Profile | 修改 Profile | My Identity |
| Identity Security | Rotate Key | My Identity Settings |
| Preferences | Language、Theme | Header、Account Menu |

Wallet Confirmation 由 Wallet 提供，不设计成本站页面。

## 5. 页面设计

### 5.1 Welcome

#### 页面结构

```text

Main
  Product Name
  Short statement
  Connect Wallet

Footer
  Language
  Theme
```

首屏直接提供 Wallet 连接，不使用营销式 Hero 或功能介绍卡片。

#### 主要文案

```text
Ownword
Own your identity. Own your words.

[Connect Wallet]
```

#### 组件拆分

```text
WelcomePage
  +-- AppHeader
  +-- BrandStatement
  +-- WalletConnect
  +-- LocaleSwitcher
  +-- ThemeSwitcher
```

### 5.2 Wallet Connection

#### 页面状态

```text
Not connected
Connecting...
Connected
Connection cancelled
Connection failed
```

多个 Wallet 可用时，先显示 Wallet 选择菜单。`Detecting`、`Selecting` 和 Provider discovery 不直接展示。

#### 页面结构

```text
Wallet Connection
  Status icon
  Status title
  Short explanation
  Primary action
  Secondary action
```

失败时提供 `Try Again`；取消后返回 Welcome。页面不显示 SDK 错误码。

#### 组件拆分

```text
WalletConnectionPage
  +-- WalletPicker
  +-- WalletConnectionStatus
  +-- RetryAction
  +-- CancelAction
```

### 5.3 Identity Resolution

#### 页面目的

连接成功后，系统解析当前 Wallet 对应的 BAP Identity，并自动选择下一页。

#### 页面分流

| 结果 | 下一页 |
| --- | --- |
| Identity 已发布，Profile 完整 | My Identity |
| Identity 未发布 | Identity Setup |
| Identity 已发布，Profile 不完整 | Identity Setup，显示 `Complete your profile` |
| 解析失败 | Resolution Failed，允许重试 |

#### 页面结构

```text
Resolving your identity...
  Progress indicator
  Current Wallet
  Cancel or Disconnect
```

解析过程不展示 `computeBapId`、`resolveBapId` 等实现名。

#### 组件拆分

```text
IdentityResolutionPage
  +-- WalletReference
  +-- ResolutionStatus
  +-- RetryAction
  +-- DisconnectAction
```

### 5.4 Identity Setup

#### 页面结构

```text
Set up your identity

Avatar
Name
Type: Person / Organization
Bio

[Cancel] [Review]
```

页面将 Identity 创建和 Profile 填写呈现为一个连续任务。用户不需要理解两者对应不同底层操作。

#### 字段交互

| 字段 | 交互 |
| --- | --- |
| Avatar | 上传或填写图片；显示预览和失败状态 |
| Name | 必填；显示剩余长度和行内错误 |
| Type | 使用 segmented control：Person / Organization |
| Bio | 可选；显示剩余长度 |

字段约束以核心认知第 7.3 节为准。

#### 组件拆分

```text
IdentitySetupPage
  +-- IdentityForm
        +-- AvatarInput
        +-- NameInput
        +-- IdentityTypeControl
        +-- BioInput
  +-- FormErrorSummary
  +-- ReviewAction
```

## 6. 共享组件

| 组件 | 职责 | 状态 |
| --- | --- | --- |
| `AppHeader` | Brand、Wallet、My Identity、Preferences | Connected / Disconnected |
| `WalletConnect` | 发起连接、选择 Wallet | Idle / Connecting / Cancelled / Failed |
| `WalletStatus` | 展示当前 Wallet 状态 | Connected / Disconnected |
| `WalletReference` | 展示当前 Wallet，避免操作对象不明 | Default / Changed |
| `IdentityReference` | 紧凑展示 Avatar、Name、BAP ID | Default / Loading / Unavailable |
| `IdentityCard` | 展示完整 Identity 摘要 | Private / Public / Review |
| `BapIdDisplay` | 展示、展开和复制 BAP ID | Default / Copied / Copy failed |
| `IdentityForm` | 创建和修改 Profile | Pristine / Dirty / Invalid / Submitting |
| `OperationStatus` | 展示 Processing、Cancelled、Failed、Success | 四种结果 |
| `LocaleSwitcher` | 切换英文、中文 | English / 中文 |
| `ThemeSwitcher` | 切换 Light、Dark | Light / Dark |

相同数据和操作必须复用共享组件，避免页面自行定义 BAP ID、Wallet 状态、Identity 摘要和偏好交互。

## 7. 视觉与响应式

### 7.1 视觉方向

Dark 是 v0.1 主视觉。页面使用 Graphite、Steel、Silver、Engraving、Stamp 等隐喻，表达身份的分量、责任和稳定。

禁止 Crypto Casino、Cyberpunk、Neon 风格。Identity 采用 `Metal Identity Plate` 方向，不使用现实身份认证徽章。

### 7.2 语义 Token

组件只使用语义 Token：

```text
canvas / surface / surface-raised
text-primary / text-secondary / border
action / metal-accent / focus-ring
status-success / status-warning / status-error
```

Dark 与 Light 共享 Token 名称。主题切换不得改变布局尺寸或内容层级。

### 7.3 响应式

Desktop：

```text
Header
Main content: max-width constrained
Identity summary and actions can use two columns
```

Mobile：

```text
Compact header
Single-column content
Primary action remains visible
Long BAP ID truncates in middle
```

所有页面必须验证中英文长文案、键盘焦点、错误状态和 320px 宽度；文本不得重叠或溢出。

## 8. BDD 验收

每个功能使用 Given / When / Then 描述可观察结果。BDD 只验证产品行为，不定义实现方式。

### 8.1 连接 Wallet

```gherkin
Feature: Connect Wallet

  Scenario: Connect successfully
    Given the user has not connected a wallet
    When the user selects "Connect Wallet" and approves the wallet request
    Then the application shows "Connected"
    And starts identity resolution

  Scenario: User cancels connection
    Given the wallet confirmation is open
    When the user rejects or closes the request
    Then the application shows "Connection cancelled"
    And returns to the Welcome page

  Scenario: Connection fails
    Given the user starts wallet connection
    When the wallet cannot connect
    Then the application shows "Connection failed"
    And offers "Try Again"
```

### 8.2 Account Switch 与 Disconnect

```gherkin
Feature: Wallet account changes

  Scenario: Switch account
    Given a wallet and identity are active
    When the wallet account changes
    Then the application cancels the current sensitive operation
    And clears the previous identity from the page
    And resolves the identity for the new account

  Scenario: Disconnect wallet
    Given a wallet is connected
    When the user selects "Disconnect"
    Then the application removes the wallet and identity context from the page
    And returns to the Welcome page
```

### 8.3 Identity 自动分流

```gherkin
Feature: Resolve current identity

  Scenario: Published identity with complete profile
    Given the wallet is connected
    And the current wallet controls a published identity with a complete profile
    When identity resolution completes
    Then the application opens My Identity

  Scenario: Identity does not exist
    Given the wallet is connected
    And no published identity exists for the current wallet
    When identity resolution completes
    Then the application opens Identity Setup

  Scenario: Profile is incomplete
    Given the current wallet controls a published identity with an incomplete profile
    When identity resolution completes
    Then the application opens Identity Setup
    And shows "Complete your profile"

  Scenario: Resolution fails
    Given the wallet is connected
    When identity resolution fails
    Then the application explains that the identity could not be resolved
    And offers "Try Again" and "Disconnect"
```

### 8.4 创建 Identity

```gherkin
Feature: Create Identity

  Scenario: Review valid identity profile
    Given the user completed all required profile fields
    When the user selects "Review"
    Then the application shows the profile preview
    And shows the BAP ID with Copy
    And shows "Your wallet controls this identity."

  Scenario: Block invalid profile
    Given a required profile field is invalid
    When the user selects "Review"
    Then the application stays on Identity Setup
    And shows an inline error beside the invalid field

  Scenario: Create identity successfully
    Given the user is on Identity Review
    When the user selects "Create Identity" and approves the wallet request
    Then the application shows "Creating identity..."
    And then shows "Your identity is ready"
    And offers "Go to My Identity"

  Scenario: User cancels identity creation
    Given the wallet confirmation for identity creation is open
    When the user rejects or closes the request
    Then the application shows "Creation cancelled"
    And keeps the profile values

  Scenario: Identity creation fails
    Given the user approved identity creation
    When creation fails
    Then the application shows "Couldn't create identity"
    And offers "Try Again"
```

### 8.5 查看与复制 Identity

```gherkin
Feature: View Identity

  Scenario: Open My Identity
    Given the current identity is active
    When the user opens My Identity
    Then the page shows Avatar, Name, Type, Bio and BAP ID
    And the BAP ID appears in the first viewport

  Scenario: Copy a shortened BAP ID
    Given the page displays a shortened BAP ID
    When the user selects Copy
    Then the clipboard receives the complete BAP ID
    And the page shows "Copied" without shifting layout

  Scenario: Copy fails
    Given a BAP ID is visible
    When the clipboard operation fails
    Then the page keeps the BAP ID visible
    And shows "Couldn't copy"
```

### 8.6 修改 Profile

```gherkin
Feature: Edit Profile

  Scenario: Save profile changes
    Given the user changed a valid profile field
    When the user selects "Save Changes" and approves the wallet request
    Then the application shows "Saving..."
    And then shows "Saved"
    And My Identity shows the new profile values

  Scenario: User cancels profile update
    Given the wallet confirmation for profile update is open
    When the user rejects or closes the request
    Then the application shows "Saving cancelled"
    And keeps the editing values on the form

  Scenario: Leave with unsaved changes
    Given the profile form contains unsaved changes
    When the user leaves the page
    Then the application asks whether to discard the changes
```

### 8.7 Rotate Key

```gherkin
Feature: Rotate Identity Key

  Scenario: Review key rotation
    Given the user opens Identity Security
    When the user selects "Rotate Key"
    Then the application shows the current Identity and BAP ID
    And states "Your BAP ID will not change."

  Scenario: Rotate key successfully
    Given the user is on key rotation review
    When the user approves the wallet request
    Then the application shows "Rotating..."
    And then shows "Completed"
    And the displayed BAP ID remains unchanged

  Scenario: User cancels key rotation
    Given the wallet confirmation for key rotation is open
    When the user rejects or closes the request
    Then the application shows "Rotation cancelled"
    And the identity remains available
```

### 8.8 国际化

```gherkin
Feature: Switch language

  Scenario: First visit
    Given no locale preference exists
    When the user opens Ownword
    Then the application displays English product text

  Scenario: Switch to Chinese
    Given the application is displayed in English
    When the user selects "中文"
    Then product text changes to Chinese immediately
    And the language preference persists after reload

  Scenario: Preserve protocol values
    Given the user changes language
    When an Identity page rerenders
    Then BAP ID and user profile content remain unchanged
```

### 8.9 主题

```gherkin
Feature: Switch theme

  Scenario: Switch to Dark
    Given the application uses Light theme
    When the user selects Dark
    Then all visible components use Dark semantic tokens
    And the theme preference persists after reload

  Scenario: Switch to Light
    Given the application uses Dark theme
    When the user selects Light
    Then all visible components use Light semantic tokens
    And the layout does not shift

  Scenario: Status remains understandable
    Given a success, warning or error state is visible
    When the theme changes
    Then the state remains readable through text or icon
    And does not rely on color alone
```

### 8.10 响应式与无障碍

```gherkin
Feature: Responsive and accessible pages

  Scenario: Use a narrow mobile viewport
    Given the viewport width is 320 pixels
    When the user opens any v0.1 page in English or Chinese
    Then text and controls do not overlap or overflow
    And the primary action remains usable

  Scenario: Navigate with keyboard
    Given the user uses keyboard navigation
    When focus moves through an interactive page
    Then every interactive control shows a visible focus state
    And icon buttons expose accessible names
```

## 9. 待确认

原型或实现前需要确认：

1. Avatar 输入方式：只允许 URL，还是支持本地图片选择与上传；
2. v0.1 首次访问默认 Theme：Dark、Light，或跟随系统；
3. Disconnect 是否只断开当前应用会话，还是同时触发 Wallet sign out；
4. Public Identity 在 v0.1 是否提供可分享 URL；
5. Key Rotation 是否保留在 v0.1，还是下放到 v0.1.1。
