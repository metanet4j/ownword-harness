## 3. 数据流

### 3.1 连接与读取

1. 连接适配取得实际 walletIdentityPublicKey，检测 network=main。通过真实 computeBapId 取得 BAP ID。
2. 请求身份 HTTP。后端从已验证投影读取；缺失时尝试配置的实际公共 BAP 查询和原始交易核验。不能用空 MongoDB 表直接判定身份未发布。
3. DTO 区分 published、incomplete、not-published、unknown。not-published 必须有成功公共查询或明确索引覆盖证据；上游不可用返回 unknown/可重试错误。
4. 钱包 basket 用于签名序列和钱包输出管理，不作为公开发布事实。若 public 已发布但 basket 缺失，先恢复实际记录；恢复不能完成则提示能力缺失，不重复发布 ID。
5. 账户事件和断开递增 epoch，终止未提交 Review，取消本地 fetch 并丢弃迟到结果。

### 3.2 创建、补全与更新

1. 表单校验产品属性。选图本地预览，真正发布前上传到真实头像服务，使用可持久读取的 URI。
2. Review 冻结 profile、bapId、epoch、operationId 和当前 profileTxid。切换账户或改变输入后重新 Review。
3. 真实 Identity Actions 编码 Schema.org、派生密钥、构造 ID/ALIAS 和 AIP。首次 ID 由根声明建立归属，ALIAS 按新声明的签名者验证。
4. wallet.createAction/signAction 完成钱包授权及回执；所有失败形式包括返回 error 都归一化。主网 live 回执需继续实际查询；不以回执存在显示 published。
5. 以 operationId 和原始交易记录操作。后端实际解析、计算 TxID、逐输出 AIP 验证、检查 BAP 归属和冻结内容；失败拒绝，不直接保存客户端 Profile 为发布事实。
6. live 分支查询网络、写入真实事件、更新投影并回读；simulated 分支只写隔离操作记录并给出模拟结果，不更新生产公开身份投影。
7. 已返回交易但读取超时进入待核实，查询同一操作；幂等重试不能发起另一笔授权。页面草稿保留，提交完成前不覆盖旧资料。

## 4. HTTP 契约

以下为本次需要新增的接口设计，不声称当前已存在。业务 DTO 与 Java 实体分离；成功为 {data,meta}，失败为 {error,meta}。

meta 必含 requestId、network、source、observedAt；source 为 chain/indexer/storage/wallet-simulation，准确表达本次结果来源。时间为 UTC ISO 8601。上游未实际取得结果时不返回伪造的 observedAt。

错误包含 code、retryable 和可选 field；固定本地文案映射，不向页面输出 Java 堆栈。常用 code：INVALID_IDENTIFIER、UPSTREAM_UNAVAILABLE、SIGNATURE_INVALID、IDENTITY_MISMATCH、PROFILE_CHANGED、OPERATION_CONFLICT、ASSET_INVALID、STORAGE_UNAVAILABLE。

### 4.1 Identity

GET /api/v1/identities/{bapId}

```ts
type IdentityResolution = {
  kind: 'published' | 'incomplete' | 'not-published' | 'unknown';
  bapId: string;
  profile: {name: string | null; type: 'Person' | 'Organization' | null;
    bio: string; imageUrl: string | null} | null;
  idTxid: string | null;
  profileTxid: string | null;
  missingFields: Array<'name' | 'type'>;
  signatureStatus: 'valid' | 'invalid' | 'unverified';
  indexCoverage: 'sufficient' | 'unknown';
};
```

200 可表示实际查询后的明确分流；未知来源不返回 not-published。400 标识非法；502 上游失败；503 存储/索引不可用。客户端必须检查 bapId 与请求一致，不能默默采用不同身份。profile 字段映射 name/@type/description/image；alternateName 仅作为明确的旧格式回退，不能掩盖没有资料。

### 4.2 原始交易与操作

POST /api/v1/identity-operations

```ts
type OperationRequest = {
  operationId: string;
  bapId: string;
  kind: 'create' | 'profile-update';
  expectedProfileTxid: string | null;
  profile: {name: string; type: 'Person' | 'Organization'; bio: string; imageUrl: string | null};
  transaction: {txid: string; rawTx: string};
};
type OperationResult = {
  operationId: string;
  bapId: string;
  status: 'submitted' | 'indexing' | 'published' | 'simulated' | 'outcome-unknown' | 'failed';
  broadcastMode: 'live' | 'simulated';
  txid: string;
  networkAccepted: boolean | null;
  identitySignature: 'valid' | 'invalid' | 'unverified';
};
```

Idempotency-Key 必须等于 operationId。首次验证完成返回 202/201；相同键、相同内容返回既有记录，不再调用钱包或广播；不同内容返回 409。字段 400、非法签名或内容归属 422、旧版本 409、数据库失败 503。

broadcastMode 由部署和测试钱包传输来源决定；普通请求不能把模拟 TxID 标成真实。live 必须从主网取得与 rawTx 相同的交易才能进入生产投影。接入阶段限制接受协议输出集合，拒绝无关交易及缺失 identityKey 证明。

GET /api/v1/identity-operations/{operationId}：查询同一记录与本次状态，404 未登记；未知不是失败。模拟入口绑定 loopback 与隔离数据库，生产部署关闭。

GET /api/v1/transactions/{txid}：实际网络读取与验签。返回 txid、visibility（unknown/observed）、networkAccepted（boolean/null）、confirmations（integer/null）、identitySignature 及每个 BAP 输出的验证结果。未观测时保留 unknown；不把 simulated 操作回执混入该接口的主网结果。

### 4.3 头像

POST /api/v1/avatar-uploads：multipart file，PNG/JPEG/WebP，初始最大 5 MiB，可配置；检查字节、MIME 与可解码性。201 返回 assetId、url、contentType、byteLength；413 超限，415 不支持，422 无效图片，503 存储不可用。

GET /api/v1/assets/{assetId}：返回真实图片字节、Content-Type、ETag 和缓存头；assetId 仅 SHA-256，不接收文件路径或任意 URL。404 不存在。上传真实写入隔离存储，重启后可读；取消编辑不删除已发布图片。生产配置 PUBLIC_ASSET_BASE_URL 必须是可公开读取的 HTTPS 地址；本地 loopback 结果仅作为本地集成证据。

写接口限制 Origin、大小、并发与上传配额，图片始终当作图片响应且不执行脚本。测试数据库及本地资产使用独立命名空间。

### 4.4 运行入口

GET /health：只有真实 MongoDB 和必需配置就绪才 ready；链查询依赖不可用单独列出，不假装 healthy。Next 同源 /api 仅转发明确 allowlist 到配置的 OWNWORD_API_URL，不接受任意代理目的地。缺配置返回可恢复错误，不返回样例成功。

## 5. 钱包完整 API 与模拟边界

生产接入从 CWI 或锁定的 connectWallet/createWalletSession 建立真实会话。测试方案使用独立的钱包测试服务持有测试钥匙；浏览器 CWI 调用完整映射到它。真实 Actions 与页面不认识模拟场景。

完整方法表以 reference/1sat-sdk/packages/wallet/src/cwi/factory.ts 为准，覆盖 28 个方法：

| 类别 | 方法 | 实现与验证要求 |
| --- | --- | --- |
| 输出 | listOutputs、relinquishOutput | 按账户/basket/tags 隔离，真实类型与分页；测试钱包状态可控 |
| 交易 | createAction、signAction、abortAction、listActions、internalizeAction | 支持 signableTransaction/reference、取消与幂等；模拟广播只返回有来源的回执，不宣称主网接受 |
| 公钥 | getPublicKey、revealCounterpartyKeyLinkage、revealSpecificKeyLinkage | v0.1 的公钥派生真实；非本期权限能力可明确 unsupported，不能伪造证明 |
| 密码学 | encrypt、decrypt、createHmac、verifyHmac、createSignature、verifySignature | 优先委托真实 SDK 钱包实现；需要调用的路径必须实际验签，不返回固定 true |
| 证书 | acquireCertificate、listCertificates、proveCertificate、relinquishCertificate、discoverByIdentityKey、discoverByAttributes | 全部存在、类型正确；未实施能力统一明确 unsupported，不将其计为证书功能完成 |
| 状态 | isAuthenticated、waitForAuthentication、getHeight、getHeaderForHeight、getNetwork、getVersion | 授权可批准/拒绝/取消，网络固定 main；高度和区块头如提供必须真实读取 |

方法覆盖检查与 v0.1 调用契约分开计数。完整方法可调用不等于完整钱包所有业务功能均实现。实际包版本及方法数在编码前再次核实。

connectWallet 将多次失败折叠为 null，本地源码不能直接提供可靠取消原因。适配层采用受控 Yours 连接及原始错误证据区分 unavailable/cancelled/failed；不能凭字符串猜用户取消。Account Switch 同时监听事件及认证/公钥变化，避免扩展事件漏送。

测试钱包钥匙不进入 Next 客户端或 Java 服务。测试接口 loopback-only，令牌及钥匙通过隔离配置读取且不输出。模拟输入/花费能力仅发生在钱包边界；原始交易的身份内容签名真实校验，资金有效性和网络确认仍为未验收。

## 6. 后端存储、解析与索引

1. MongoDB 分开保存 chain_events、identity_projection、identity_operations、simulated_operations、avatar_assets。模拟结果不能进入前两者。
2. 真实事件唯一键 network+txid+vout，保留原始字节/来源摘要、块位置、签名和观测时间。重复摄入、重启重放及失败重试不重复写资料版本。
3. 每笔交易逐输出识别 BAP 与 AIP。首先验证根 ID 的派生关系和声明，再验证同交易 ALIAS。历史签名按当时有效地址判断，不只查当前 rootAddress。
4. 旧 MongoBapService 的 Optional.get 缺失处理、Identity.name 映射、首次双输出解析需定向修复并有真实输入验证。旧 Planaria JSON 不作为新钱包原始交易的已验证兼容入口。
5. 公共索引路径先核实真实 endpoint、响应与覆盖范围。可复用已验收 JungleBus 客户端接入原始交易，业务仍负责解析、持久化、排序和重建。既有匿名订阅样本不能证明包含本次测试交易；发布测试须确认本次 txid 被实际索引。
6. 资料排序以验证过的链关系与区块位置为依据；无链序证据的冲突返回 unknown，不按客户端 Date.now 选择最新。重组先回滚受影响主链投影，再重放；无法取得必要信息时显示待核实。
7. 不要求启动本期不需要的全部中间件；最小应用需要真实 MongoDB、真实文件持久化、主网查询。需要其它设施时沿用共享 infra。
