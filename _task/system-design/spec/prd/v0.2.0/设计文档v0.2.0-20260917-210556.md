# Ownword 产品设计 v0.2.0

> Content / Markdown / Identity Signing / Publish / Revision

## 0. 文档定位

本文沿用 [v0.1 设计文档](../v0.1/设计文档v0.1.md)的组织方式，定义版本目标、范围、页面、组件、交互状态和 BDD 验收，并给出高保真原型的制作映射。

交付物是可交互的高保真原型。编辑、预览、导入导出和本地草稿可实际操作；身份签名、钱包授权、交易广播、链上查询和 Proof 使用可控样例。本文不设计生产 API、数据库、钱包适配、密码学实现或链上协议字段。

[核心认知](../../核心认知.md)是全局事实的唯一来源。本文只定义 v0.2.0 的界面与原型行为；模拟成功不能作为真实签名或真实上链的证据。任务进度以 [harness 功能清单](../../../../prototype-worktree/ownword-v0.2.0/feature_list.json)为准。

## 1. 版本目标

在当前身份原型之上完成文字内容闭环：从“我的内容”新建或导入 Markdown，编辑并预览，保存草稿，以明确身份检查、签名和发布，阅读结果，再追加新版本。

用户应能在原型中判断：正在用谁的身份发布、签名授权发生在哪里、发布是否成功、链上是否确认，以及失败后正文是否保留。签名与链上发布是本版必备交互，不能用一个直接跳到成功页的按钮代替。

### 2.2 非目标

不制作图片上传或嵌入、附件、音视频、公式、Mermaid、任意 HTML、AI 写作、协作编辑、问答、评论、点赞、转发、关注、标签体系、推荐流和全局搜索。不接真实钱包、密钥、签名服务、广播、索引器或后端数据库，不产生真实交易或费用。

v0.1 的身份入口、公开身份卡、语言和主题作为基线复用；不借内容版本重做身份模块。

## 3. 全局产品规则

遵循核心认知第 6.1、6.3、7.4、7.5、9.3、10.1、10.3、10.5 节，原型重点呈现以下约束：

- 编辑源始终为同一份 Markdown。预览清理、主题和语言切换不改写正文。
- Review 显示当前身份与公开影响；复制 BAP ID、TxID 时返回完整原值。
- 授权取消和系统失败分开表达，均保留可恢复的草稿。
- 业务发布结果与链上确认独立展示；“已发布”不等于“已确认”。
- 已发布正文只读；修改通过创建修订产生新版本，旧正文与旧链接保留。
- 切换账户或断开连接终止未提交的敏感操作，不用新身份继续旧操作。已提交的操作不显示“已撤回”。
- 原型沿用场景面板集中说明模拟边界。钱包确认区域明确标为模拟授权；样例交易不跳转到真实区块浏览器，不伪装成已完成密码学校验。

## 4. 页面、组件与交互设计

### 4.1 页面结构

| 页面 | 入口与主信息 | 主要操作 | 必备状态 |
| --- | --- | --- | --- |
| 我的内容 | 我的身份页“我的内容”；当前作者摘要、草稿/已发布筛选、内容列表 | 新建、打开草稿、阅读已发布内容 | 初次空白、筛选无结果、加载、加载失败 |
| Markdown 编辑器 | 新建、打开草稿或创建修订；作者、保存状态、工具栏、源码与预览 | 导入、导出、预览、检查发布、返回 | 空白、编辑中、保存中、已保存、保存失败、超限、修订无改动 |
| 发布确认 | 编辑器“检查发布”；只读正文、作者与 BAP ID、公开影响 | 返回修改、签名并发布 | 可确认、身份失效、快照已失效 |
| 发布进度与结果 | 确认后；签名授权、签名处理、发布处理、业务结果 | 授权/取消、按结果重试或查询、阅读内容、返回草稿 | 等待签名、签名中、发布中、成功、取消、失败、待核实 |
| 内容详情/公开阅读 | 工作台、发布成功或版本链接；正文优先，作者/版本/时间次之 | 复制链接、导出、本人创建修订、查看历史、展开 Proof | 当前版本、历史版本、访客只读、加载失败、内容不存在 |
| 版本历史 | 详情“版本历史”；按版本倒序显示时间、版本号与当前标记 | 打开任一版本、回到最新版本 | 首个版本、多个版本、历史版本缺失 |

发布进度与结果共用一个视图；Proof 是详情页的展开区。保留清晰返回路径，不为每种错误增加独立页面。原型使用 hash 路由，使刷新、浏览器后退与版本链接能恢复对应视图。

### 4.2 视觉与组件

继承当前“穹顶与地平线”品牌、字体和 React Spectrum S2。写作与阅读页减少装饰，正文为主视觉；不把整篇正文放进多层卡片。内容列表使用标题、两行摘要、状态与时间，整行可打开，删除位于次级菜单。

复用现有页头、身份摘要、按钮、Tabs、Menu、Dialog、Toast、状态提示和标识复制组件。新增内容列表项、Markdown 编辑区、Markdown 正文、保存提示、发布阶段、版本列表和 Proof 展开区；颜色、字号、间距、圆角均取 S2 token，状态不只靠颜色表达。

桌面宽度达到 960px 时，编辑器默认源码/预览双栏，可切换单栏；低于 960px 默认编辑，使用“编辑/预览”切换，同一份正文和光标状态保持。阅读正文最大宽度约 72ch。320px 下工具栏按组收起到“更多”，主要操作可见，代码与表格在自身容器横向滚动，页面不横向溢出。

焦点随页面进入主标题；弹窗关闭后回到触发点。工具栏可用键盘操作，图标按钮有名称，保存反馈不抢焦点。输入法组合输入期间不触发格式快捷键；减少动态效果偏好下取消装饰动画。

### 4.3 Markdown 体验

参考 xLog 的写作交互，保留 Ownword 的视觉系统，不复制 xLog 的站点管理功能。具体参考依据见第 10 节。

- 编辑模式：源码编辑，带语法提示；预览延迟约 500ms 更新，开始 Review 时使用最新正文，不能使用尚未刷新的预览缓存。
- 工具栏：一级至三级标题、粗体、斜体、删除线、引用、有序/无序/任务列表、链接、行内代码、代码块、表格和分隔线。选中文字时包裹选区，无选区时插入占位并选中；一次操作可撤销。
- 预览范围：标题、段落、强调、引用、列表、任务列表、链接、代码块、表格、分隔线。预览中的任务框只读，修改回到源码完成。
- 桌面编辑和预览按对应段落同步滚动，预览中主动滚动时不争抢位置；手机切换回编辑保持光标与滚动位置。
- 不支持的媒体、公式、图表和 HTML 按原始文本表达，并给出一次提示；不加载媒体或执行 HTML，不静默删除源码。危险链接不可点击；普通链接在新标签打开。
- 标题取首个一级标题的纯文本，不维护另一份标题字段；无一级标题时显示“未命名内容”，正文非空仍可检查发布。列表摘要从正文派生，不单独编辑。

本版原型以 100 KiB（102,400 个 UTF-8 字节）作为正文样例与导入上限，不代表链上协议限制。手动输入超限保留全文、提示原因、允许导出，阻止检查发布；超限文件拒绝导入。空正文指去除空白后为空。界面字数按非空白可见字符统计；UTF-8 字节数用于上限判断，二者不混用。

### 4.4 草稿与文件

停止输入约 800ms 后自动保存；显示“保存中”“已保存”或“保存失败”。本地持久化以当前 BAP ID 隔离。恢复的是该身份最后保存成功的内容；另一个身份不得看到或继续其草稿。存储不可用时仍可编辑和导出，但不显示“已保存”。

内部离开且尚有未保存内容时，提供“继续编辑”“保存并离开”“放弃未保存修改”；保存失败留在编辑器。刷新/关闭标签时，对尚未保存内容使用浏览器原生提醒。删除只针对本地草稿，确认中显示标题；不提供删除已发布内容入口。

导入只接受 UTF-8 `.md`，支持 UTF-8 BOM 并在解码时移除 BOM，保留正文换行与内容。格式、编码、大小错误不替换当前正文。已有非空正文时，先确认“替换当前草稿”，取消不改变内容；保存失败或未保存时先完成上述离开保护。导出直接使用当前原始 Markdown，不导出渲染后的 HTML，不重排或改写源文本。

### 4.5 确认、签名与发布

确认页按“作者及完整 BAP ID—正文预览—公开影响—操作”排列。公开影响说明：正文将公开；发布后不能覆盖，只能追加新版本。主按钮为“签名并发布”，次按钮为“返回修改”。费用不虚构报价，在模拟钱包中说明本次演示不产生费用。

Review 固定当前正文与作者快照。回到编辑修改正文，或发生身份变化时，旧确认与旧签名结果失效；必须重新检查。不得签预览 HTML，也不得在签名后悄悄改写正文。

| 交互阶段 | 页面反馈与可操作行为 | 结束方式 |
| --- | --- | --- |
| 等待身份签名授权 | 模拟钱包说明当前身份与签名内容；可授权、取消 | 授权后进入签名；取消返回草稿并提示“签名已取消” |
| 身份签名中 | 显示“正在签名”，阻止重复请求 | 成功显示签名步骤完成，再进入发布；失败保留草稿并允许重试 |
| 链上发布中 | 显示“正在发布”，与签名步骤区分 | 网络接收样例进入成功；明确拒绝进入失败；响应丢失进入待核实 |
| 发布成功 | “内容已发布”，独立显示“确认中”或“已确认”；提供阅读入口 | 可展开交易样例，或返回我的内容 |
| 发布失败 | 说明失败阶段与正文已保留；允许返回编辑或重试 | 重试前重新核对当前身份和快照，不复用失效授权 |
| 结果待核实 | 不宣称成功或失败；显示已有操作记录与“查询结果” | 样例查询返回已接收、仍待核实或明确未接收；只有明确未接收后才可重新发布 |

签名成功不等于已发布。连续点击只发起一次当前操作。发布已提交后切换身份，旧记录保留在原身份下；新身份界面不接收旧操作的成功提示，不能用“取消”暗示链上回滚。

场景面板提供签名取消/失败、发布拒绝、结果待核实、确认中、已确认和账户切换入口。默认走正常流程；每个阶段由明确动作或短暂处理状态推进，禁止随机失败。

### 4.6 阅读、版本与 Proof

公开阅读不要求连接钱包。样例库支持可复现的公开文章链接；用户在浏览器中新发布的演示内容仅保存在当前 origin，复制链接后在同一浏览器可重开。跨浏览器或清除本地数据后找不到该内容时，明确显示“未找到此演示内容”，不伪称已从链上恢复。

新建修订沿用原作者，复制原文成为独立草稿；未改动或改回原文时不能检查发布。成功后生成新的样例版本与交易标识；历史正文保持不变。历史阅读页标注版本，提供“查看最新版本”。访客不出现作者修改操作。

Proof 折叠摘要使用中性“签名与链上记录”。展开后分别展示作者 BAP ID、内容签名状态、完整可复制样例 TxID、链上确认状态和查询样例来源。模拟有效、未验证、验证失败三态均可从场景面板进入；正文被改动或签名不匹配样例不得显示有效。样例字段明确标注，不宣称实际执行了密码学验证。

## 5. BDD 验收

每行使用 Given / When / Then 表达可观察结果。编号同时用于功能清单、原型制作与验证证据，避免另建需求副本。

| 场景 | Given（前置） | When（动作） | Then（结果） |
| --- | --- | --- | --- |
| C01-A | 当前身份已有草稿和发布样例 | 打开我的内容并切换筛选 | 只显示对应内容，新建和打开入口可用 |
| C01-B | 空内容或模拟加载失败 | 打开工作台 | 显示空状态或重试，不把错误显示成空列表 |
| C02-A | 选中一段文字 | 点击粗体，再撤销 | 正确包裹选区，撤销恢复；中文组合输入不被截断 |
| C02-B | 手机端已输入长文 | 切换预览再回到编辑 | 正文、光标与滚动位置保持，工具栏可用 |
| C03-A | 一份含所有支持语法的样例 | 依次查看预览、Review、阅读 | 正文结构与排版一致 |
| C03-B | 含宽表格、长链接、媒体和危险 HTML | 查看预览 | 页面不横向溢出；非文字内容不加载，危险内容不执行，源码保持 |
| C04-A | 停止输入且保存成功 | 刷新后打开草稿 | 同一身份恢复最后保存内容 |
| C04-B | 模拟存储写入失败 | 输入后离开，选择保存并离开 | 显示失败且留在编辑器，可导出；切换身份后不可见旧草稿 |
| C04-C | 已有草稿 | 确认删除，再取消另一份草稿删除 | 已确认项消失，取消项保留；发布内容无删除入口 |
| C05-A | 有 UTF-8 中文 Markdown 文件 | 导入后导出 | 原始正文与换行保持，BOM 按第 4.4 节处理 |
| C05-B | 文件编码错误、超限或当前有未保存内容 | 尝试导入或取消替换 | 错误或取消不覆盖现有正文，保护流程可恢复 |
| C06-A | 当前身份有非空、未超限草稿 | 检查发布 | 显示最新正文、当前作者、完整可复制 BAP ID 和公开影响 |
| C06-B | 正文空白、超限或确认后修改了正文 | 检查发布或继续旧确认 | 无效正文被拦截；修改后必须重新 Review |
| C07-A | Review 有效 | 授权签名并完成正常发布样例 | 顺序出现签名和发布；成功后显示已发布及独立确认状态，重复点击不生成多个版本 |
| C07-B | 等待授权或模拟签名失败 | 取消或触发失败 | 分别显示取消/失败，正文保留，没有已发布记录 |
| C07-C | 签名完成后发布被拒绝 | 返回草稿、重新 Review 并重试 | 内容保留，新操作通过正常流程发布 |
| C07-D | 模拟发布响应丢失 | 查询结果 | 不直接重复发布；已接收进入成功，未明保持待核实，明确未接收才开放重试 |
| C07-E | 授权未完成，或发布已提交 | 切换账户或断开 | 未提交操作失效；已提交记录保留在原身份下，不用新身份继续，不宣称撤回 |
| C08-A | 已发布样例或本机演示内容存在 | 打开、刷新、复制链接再重开 | 同版本正文可读，导出保持源文，标识复制完整 |
| C08-B | 访客或未知内容标识 | 打开公开链接 | 访客只读；未知标识显示未找到，不呈现空白成功页 |
| C09-A | 作者查看已发布内容 | 创建修订、修改并发布 | 新版本可读，旧链接仍为旧正文，历史可往返 |
| C09-B | 修订未改动或改回原文 | 尝试检查发布 | 提示暂无修改，不进入签名流程 |
| C10-A | 处于模拟签名有效、链上未确认样例 | 展开 Proof | 两类状态分开显示，样例标识可复制，无真实区块浏览器假链接 |
| C10-B | 模拟未验证或签名不匹配 | 展开 Proof | 明确显示未验证或失败，不显示有效状态 |
| X01 | 编辑中或 Review 已打开 | 切换中英、浅深主题 | 只改变界面；正文、作者、标识与确认快照不变 |
| X02 | 320px 页面或键盘操作 | 完成当前主流程并关闭弹窗 | 无页面溢出，焦点可见且可返回，主要操作可达 |

## 8. 验证与交付

每个功能默认验证一个正常场景和相关边界，查看受影响的桌面与手机截图，记录浏览器错误；若发现关联问题再扩大范围。使用宿主环境中的 `agent-browser`。基线模型检查只能证明已有行为，不计为内容功能验收。

每项在 `feature_list.json` 记录场景编号、实际操作、截图/日志路径和限制。界面模拟应可重复复现；签名与链上结果只验收界面与状态，不要求真实 TxID。交付时明确哪些是已完成页面、哪些仍是设计，禁止用静态成功页宣称闭环完成。

功能实现并验证后提交代码，状态为 `needs-review`；用户复核前不标记 `done`。功能间依赖可在前项已实现、验证且不存在阻塞问题时继续，不需要把每项技术验证变成新的许可流程。整体 v0.2.0 交付须完成 C01–C10、X01/X02 的适用验收，并获用户视觉复核。

## 9. 版本决策与待确认

已确定：高保真交互原型、文字内容、xLog 式 Markdown 编辑、必备签名与发布流程、继承 S2 与当前 dev、任务目录下独立 worktree。第 4 节标题、尺寸、保存间隔等为本版可执行的界面设计决策，可在视觉评审后调整；它们不新增协议规则。

当前没有阻塞原型制作的待确认项。真实钱包能力、真实费用、生产索引状态映射与 Revision 协议接入不属于本版原型验收；后续产品实现须另立任务取证。全局尚未确认的事实仍以核心认知第 12 节为准，不在此推定结论。
