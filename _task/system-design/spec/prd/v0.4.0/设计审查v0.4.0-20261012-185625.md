## 一致性与制作范围

- 公开浏览、关注与粉丝列表均不要求 Wallet 连接；当前操作 Identity 与主页 Identity 独立。
- Follow 与 Friend 独立，单方申请不能显示已是好友；接受仍须对方授权，不以路由修改获得权限。
- 未知关系和未知提交结果先查询，取消、失败与索引同步分开；人数不由已加载行数替代。
- 独立媒体沿用 Post，不扩展生产发布编辑器；安全渲染、实际播放、停止后台声音和来源归属均有验收。
- 十项功能与 32 条 BDD 完整对应；生产 Friend 派生与归并、公开媒体适配仍按核心认知第 12 节验证，不阻塞模拟流程设计。
- S2 视觉与组件选型有现有资料依据；具体 v0.3.0 文件、路由和页面符合性必须在源码恢复后核实，当前不把旧版截图或组件名当作实现验收。
