# Ownword 产品设计 v0.4.0

> Personal Homepage / BAP ID / Identity / Content Showcase

## 0. 文档定位

本文沿用 v0.2.0 设计文档组织方式，定义 v0.4.0 个人主页版本目标、范围、页面、组件、交互状态和高保真原型映射。

交付物为可交互的高保真原型。本文只定义个人主页界面与原型行为，不设计生产 API、数据库、钱包适配、密码学实现或链上协议字段。

核心认知作为全局事实来源。本版本基于已有 Identity 与 Content 原型能力，扩展公开个人主页体验。页面设计遵循核心认知第 10.5 节定义的 Spectrum S2 固定设计系统及「秩序清晰、关系可感知、密度适当、表达准确」四项设计原则。

## 1. 版本目标

在已有身份原型和内容原型基础上，建立公开个人主页闭环：

用户通过 BAP ID 展示个人身份，通过主页展示个人资料与已发布内容，使访客能够确认身份、浏览内容并理解内容归属。

用户应能在原型中判断：当前主页属于谁、身份标识是什么、哪些内容由该身份发布，以及内容版本和证明信息如何关联。

## 2. 范围

### 2.1 本版本功能

| 编号 | 功能 | 原型交付 |
| --- | --- | --- |
| P01 | 公开个人主页 | BAP ID、个人资料、内容聚合展示 |
| P02 | Identity Hero | Avatar、Name、Bio、BAP ID 首屏展示 |
| P03 | 身份卡片 | 身份信息、发布记录、证明信息展示 |
| P04 | 内容展示 | 已发布内容列表、摘要、作者、版本信息 |
| P05 | 内容阅读入口 | 从个人主页进入公开内容阅读 |
| P06 | 版本关联 | 展示内容版本历史与当前版本关系 |

### 2.2 非目标

不制作社交关系、关注、推荐流、评论、点赞、即时通讯、内容交易和真实链上身份服务。

不替代 v0.2.0 内容编辑、发布和阅读能力，仅作为公开展示入口扩展。

## 3. 全局产品规则

- BAP ID 是个人主页身份根节点。
- Identity 与 Content 分离，内容通过 authorBapId 关联身份。
- 已发布内容只读，版本变化通过新版本表达。
- 公开主页展示事实信息，不伪造真实链上证明。
- 高保真原型优先表达用户体验和交互状态。

## 4. 页面、组件与交互设计

### 4.1 页面结构

个人主页是独立的公开页面，具有独立访问地址和页头，与应用中的身份、Artifact、内容管理工作区分开。作者署名、身份查找与“查看个人主页”入口均进入该页面。主页保留身份信息与内容聚合，文章进入既有阅读页，返回时回到对应作者主页。

个人主页定位为身份面向外界的展示窗口。首要信息是作者是谁、发布了什么，主要操作是阅读与分享；身份记录和证明信息按需展开。公开展示不要求连接钱包，页面不承载内容编辑、资产管理或钱包操作。

身份搜索结果中的作者姓名和“查看个人主页”均为原生链接，在新标签页打开公共主页，原搜索词与结果保留。公共主页采用个人网站构图：Ownword 品牌图标与作者名字共同作为页首标识，头像、姓名与简介组成介绍区，内容列表紧接其后；完整 Ownword 平台署名位于页脚。BAP ID 与数字 ID 以紧凑信息行展示，BAP ID 可缩略显示但复制完整值。身份记录在内容列表之后按需展开。

| 页面 | 入口与主信息 | 主要操作 | 必备状态 |
| --- | --- | --- | --- |
| 个人主页 | 独立 BAP ID 公开入口；作者资料、内容列表 | 阅读内容、分享主页、查看身份 | 正常、空内容、加载失败 |
| Identity Card | 身份展示区域 | 查看完整身份、复制 BAP ID | 正面、证明信息展开 |
| 内容展示 | 已发布内容集合 | 打开内容阅读 | 有内容、无内容 |
| 内容阅读 | 内容详情页 | 阅读、查看版本 | 当前版本、历史版本 |

### 4.2 视觉与组件

继承现有穹顶与地平线品牌，固定使用 Spectrum S2 设计系统。页面结构、内容关系、信息密度和视觉表达遵循核心认知第 10.5 节，不在本版本重复定义设计原则。

复用身份摘要、标识复制、内容阅读、状态提示等组件。

个人主页采用 high-end-visual-design 的 Soft Structuralism 与 Editorial Split：白色或深灰底面、宽留白、悬浮胶囊导航；桌面左侧以大字无衬线姓名、头像和简介介绍作者，右侧展示文章卡片。首篇文章的标题更大，日期与版本分列卡片顶部，作者与阅读入口位于底部。文章容器分为外壳与内容内层，圆角保持同心关系，阅读箭头嵌入独立圆形底面。

小于 768px 时转为单列、16px 页边距，作者信息在前，文章顺序不变。深色主题使用分层灰度与低亮度高光，避免边缘过亮。入场采用 IntersectionObserver 触发的淡入上移，悬停和按压仅改变 transform；使用自定义 cubic-bezier，遵循减少动态效果偏好。

字体、颜色、图标、标准控件与状态仍遵循绑定的 Spectrum S2，不另外引入字体、图标或组件系统。展示区应用技能的构图和表面层次；导航只有阅读、分享与偏好操作，不增加全屏菜单。头像缺失时使用姓名缩写，不虚构人物照片。

## 5. 高保真原型映射

页面重点：

1. 个人主页首屏突出作者与简介，并清楚展示 BAP ID 身份。
2. Identity Card 表达人与内容归属关系。
3. Content Showcase 展示个人创造内容。
4. Content Reader 继承 v0.2.0 阅读体验。
