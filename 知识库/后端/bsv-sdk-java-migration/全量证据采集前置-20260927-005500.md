## 使用接口

`full-evidence-locals.json` 显式列出局部 catalog、mapping、input plan、独立输入与断言、运行 manifest、Jest/Surefire 报告。无需猜测缓存中的哪个文件有效。增添一个局部输入项必须提供这套路径。

```bash
python3 full-evidence-preflight.py \
  --output .cache/evidence/full-preflight.json \
  --plan-output .cache/evidence/full-plan-candidate.json \
  --require-ready
```

当前命令预期退出 1，并保留缺口报告。`--java-report` 可重复，用于对照一套已备份 Surefire XML；不传时报告中的执行观察为未知。`--plan-output` 仅输出通过结构检查的候选计划，缺少全量覆盖时不能交给最终验收。

同用例出现不同样本、断言、语义或循环约束时，拒绝整份冲突输入。旧 producer、旧 Java revision、同一物理文件冒充两侧、错误 side/runId、缺失样本、修改后的源文件或 Java 映射均不能计入当前证据。局部计划冲突、用例缺口、Java 身份复用或缺少完整采集接口时，`--run-dir` 拒绝生成运行序列。

## 最终运行顺序与适配器契约

剩余工作应先补齐 5329 个用例的输入计划及实际采集，再执行一次完整流程。现有 `capture-*-side.py` 的局部命令含测试过滤，各自执行 `clean test`；必须整合为两端完整适配器，不能把它们连续调用后作为单次全量运行。

完整适配器接收 `evidence-bundle.py capture` 注入的 `EVIDENCE_RUN_ID`、`EVIDENCE_SIDE`、`EVIDENCE_INPUT_PLAN`、`EVIDENCE_INPUTS_PATH`、`EVIDENCE_ASSERTIONS_PATH`。每个输入行记录本侧实际消费的 `caseId/sampleId/value`，每个断言行记录本侧实际产生的 `caseId/assertionId/value`，两种行均带本次 runId/side。Java 从固定 TS 语料重放后记录实际消费值；禁止复制 TS 输入文件冒充 Java 消费记录。

TS 适配器执行冻结清单全部原文件，包含原规模 AESGCM manual；沿用离线网络防护。普通 Jest 与 manual 可以在同一 capture 包装命令内顺序执行，分别产生原始报告。manual 先使用 90 分钟时限，若不足再按用户授权提高到 180 分钟，不缩小输入。Java 适配器执行一次无过滤 `./mvn.sh ... clean test`，立即将本轮全部 Surefire XML 复制到新运行目录，避免后续 clean 覆盖。两端均须输出完整 5329 例的输入与断言轨迹，动态和条件站点按现有门禁核验。

实现完整适配器后，在配置新增 `fullRun` 对象：

- `tsCommand`、`javaCommand`：真实完整适配器的命令参数数组，Java 数组须包含按序的 `clean`、`test`，不接受 `-Dtest=` 或跳过测试参数。
- `tsReports`、`javaReports`：完整原始报告的路径数组，均相对于新运行目录；Java 数组列出本轮所有 Surefire XML。
- 命令参数中的 `{runDir}` 会替换为新运行目录绝对路径。报告路径禁止逃出该目录。

准备好完整计划和上述接口后执行：

```bash
python3 full-evidence-preflight.py \
  --config full-evidence-locals.json \
  --output .cache/evidence/full-preflight.json \
  --require-ready --run-dir .cache/evidence/full-final-20260927
```

通过前置后，新目录包含运行前固定的 `input-plan.json` 和 `commands.json`。后者依次为 TS capture、Java capture、完整 bundle、无过滤 `audit-tests.py check` 四个参数数组。以下入口可逐条执行，遇到任何失败立即停止；含集成/接口测试，必须由宿主提权工具执行：

```bash
python3 - <<'PY'
import json
import subprocess
from pathlib import Path
folder = Path('.cache/evidence/full-final-20260927')
for command in json.loads((folder / 'commands.json').read_text()):
    subprocess.run(command, check=True)
PY
```

运行前仍须完成 `module-scope.json` 的实际范围复核，以及无过滤 API gate。最终采集期间固定 TS、Java、catalog、mapping 和计划；原始轨迹必须来自上述两个独立运行。只有最后完整 `check` 通过才具备正式验收结论。
